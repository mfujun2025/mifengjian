气动 O 型圈选型：低压、无油、高频下与液压相反的取舍

2026-10-05　·　技术文章

一条 1 mm 的漏气孔，在 0.7 MPa 下每分钟漏 68 升，一年漏掉 3.5 万度电——差不多是两个三口之家的全年用电。压缩空气看不见摸不着，漏了没有油渍也没有水痕，被发现和处理的优先级永远排在最后。而气动系统里绝大多数漏点，恰恰是最不起眼的接头和端盖。

更常见的坑在选型上：很多人直接拿液压那套经验来挑气动 O 型圈——压力越高越要硬圈、要留挡圈、压缩率往区间下限取。这些结论搬到气动上，至少有三条是反的。下面只讲和液压不一样的地方。

一、先看清气动和液压差了多少

不是差一两成，是一个数量级。

维度 液压系统 气动系统
常用工作压力 10 ~ 30 MPa 0.4 ~ 0.8 MPa，重载约 1.6 MPa
工作介质 矿物油 / 水基液 / 合成液 压缩空气（可压缩）
分子尺度 油分子大，油膜还帮着一块封 氧、氮分子极小，变细的截面就是漏点
润滑条件 介质自带润滑 干燥空气几乎无润滑，只能靠自润滑材料
主要失效模式 挤出咬伤、热老化 磨损、硬化、永久变形、漏气
挡圈需求 约 10 MPa 起必须评估 常规压力下几乎用不到

三点直接后果：气动几乎不会发生挤出损伤；寿命更多取决于磨损和永久变形；同样的间隙，油不漏气漏，因为气体分子小两三个数量级。

二、反向判断一：硬度往软走，不是往硬走

液压选硬度的逻辑是"压力越高、硬度越高"，因为高压会把橡胶推进间隙里挤破。气动的压力低一到两个数量级，这个前提不存在了。

低压下真正决定漏不漏的是贴合：橡胶要能填满配合面的微观不平，把接触应力铺开。硬度越高越难贴合，低压下越容易在微观凹谷留出通道。所以气动的硬度往下走。

密封位置 推荐硬度 说明
接头、端盖、阀体等静密封 60 ~ 70 Shore A 靠压缩量贴合，不需要抗挤出
气缸活塞、活塞杆往复动密封 70 ~ 80 Shore A 兼顾贴合与耐磨
气动马达等旋转部位 75 ~ 85 Shore A 摩擦热敏感，不宜选过硬
高压气动（气动工具、增压缸、气瓶） 85 ~ 90 Shore A 此时才切回"硬圈抗挤出"

一条例外：压力超过 1.6 MPa 或配合间隙偏大时，逻辑切回液压那一套——升到 85~90A 并评估挡圈。口诀是：间隙能把圈挤过去就上硬圈，挤不过去就上软圈。

三、反向判断二：压缩率数值不变，但拉伸率必须归零

压缩率的数值区间和气动、液动没有关系。站内选型工具按密封形式给的口径是：静态端面 20%~25%、静态径向 15%~20%、往复动密封 12%~18%、旋转 8%~12%。变的不是区间，是你在区间里取哪一端。

液压往下限取——高压下压缩量越大，摩擦热和永久变形越严重，还得留出溶胀余量。气动没有这个负担：压力低、发热少，压缩量本身就是唯一的密封力来源，所以往区间上限取。

真正容易出事的是另一个参数：拉伸率。

密封形式 介质 拉伸率参考值
静密封 液压油 2% ~ 4%
静密封 压缩空气 ≈ 0（不超过 1%）
往复动密封 液压油 ≈ 2%
往复动密封 压缩空气 ≈ 0（不超过 1%）

液压圈拉伸 2%~4% 算正常，气动圈必须压到 1% 以内，最好按 0 算。 原因有两层：一是氧、氮分子直径只有零点几纳米，比油分子小得多，任何被拉细的截面都是现成的通道；二是拉伸让截面变细，等于把压缩率悄悄扣掉几个点，而低压下本来就没有余量可扣。

现场动作：气动圈的内径按沟槽内径直接选，宁可略微偏大，也不要为了"装紧一点"去拉伸。 没有型号时先量沟槽内径和槽深，再去 选型工具 反查规格；别拿旧圈量尺寸——用过的圈已经永久变形了。

四、气源里带的是油还是水，决定材质

压缩空气里通常同时带三样东西：颗粒、水、油。站内工具页里十种常用材质的 air 一栏全部是推荐——空气本身不挑材质。选材的分岔不在空气，而在气里带的是油还是水。

气源状态 推荐材质 明确不能用 原因
含油雾（有油润滑器、油润滑空压机） NBR（默认）、高温用 FKM EPDM、VMQ 乙丙与硅橡胶都不耐矿物油
无油干燥（无油空压机 + 吸附式干燥） PU、含内润滑剂 NBR、PTFE 复合 普通 NBR 长期干磨 干燥空气没有润滑膜
含水（冷干机效果差、管路有冷凝水） EPDM、PTFE 复合 PU（会水解） 酯型聚氨酯遇水发软掉强度
洁净 / 食品医药接触 EPDM、VMQ（食品级牌号） 普通 NBR 需要接触认证
高温或腐蚀性气体 FKM，更强用 FFKM NBR、PU 温度与介质双重超界

两条最容易踩的红线：

  • 有油雾的气源，绝对不能上 EPDM 和 VMQ。 乙丙橡胶与硅橡胶都属非极性，遇矿物油迅速溶胀，而气动系统里的润滑器用的正是矿物油。这是气动里最常见的"材质升级变降级"。
  • 无油又含水时，PU 和 EPDM 会互相打架。 无油空气要自润滑耐磨的 PU，可 PU 会水解；EPDM 耐水却不能沾油。而最典型的场景恰恰是无油空压机配了台没配好的冷干机，管路里全是冷凝水。此时要么用耐水解牌号的 PU 并缩短更换周期，要么走 EPDM 并确认气源无油，没有一种材质能同时解决这两头。

气源里究竟有多少颗粒、多少水、多少油，用 ISO 8573-1 的三个数字描述，写成 [颗粒 : 水 : 油]：

等级 颗粒（0.1~5 μm 每 m³） 水分（压力露点） 含油量
Class 1 ≤ 20,000 ≤ -70℃ ≤ 0.01 mg/m³
Class 2 ≤ 400,000 ≤ -40℃ ≤ 0.1 mg/m³
Class 3 ≤ 90,000（只控 0.5~5 μm） ≤ -20℃ ≤ 1 mg/m³
Class 4 只控 5 μm 以上 ≤ +3℃ ≤ 5 mg/m³

读这张表只有一条要点：三个数字必须分开看，油分 1 级不代表水分也是 1 级。通用气缸与气动工具油分压到 3~4 级就够，食品、医药、涂装要 1~2 级。一旦无油和低露点同时要求，材质就被逼到 PTFE 复合或弹簧蓄能圈上——PTFE 本身没有弹性，必须靠弹簧或挡圈提供压紧力，纯圈在低压气动里撑不住。

五、高频动作带来的两个新麻烦

气缸的动作频率比液压缸高得多，一分钟几十次很常见，下面两个问题在液压里不突出：

一是摩擦热与磨损。 干燥空气没有润滑膜，圈每走一个行程都在干磨。同一只圈，在液压里泡着油能用两年，在气动里可能几个月就磨出平台。高频场合优先选耐磨材料（PU、含内润滑剂 NBR、PTFE 复合），别用普通 NBR 硬扛。邻近电机的场合还要留神臭氧——NBR 双键含量高，极易被臭氧老化开裂。

二是低速爬行。 气缸在低速轻载下容易一顿一顿地走，根子在静摩擦远大于动摩擦。这时候要的是低摩擦而不是高密封力：适度降低压缩率、选 PTFE 复合或弹簧蓄能结构。这与前面"压缩率往上取"是一对矛盾——高频高压优先保密封，低速轻载优先保顺畅，两边不可能同时最优。

另外，压缩空气节流降温，干燥不到位的管路外壁会结霜，圈在低温侧变硬变脆，表现为天一冷就漏。

六、漏得最多的地方不是气缸，是接头

现场排查最容易被忽略的事实：泄漏主要发生在软管接头、气动三联件、快换接头、电磁阀、螺纹连接和气缸端盖，全是静密封。 大家习惯盯着气缸，但动密封往往不是漏得最狠的那个。

这些静密封数量多、单点小、又藏在管路角落里，不专门查一遍根本发现不了。

漏孔直径 泄漏量（0.7 MPa） 年泄漏量（24h × 365d） 折算年耗电
0.5 mm 17 L/min 8,935 m³ 约 880 度
1 mm 68 L/min 35,740 m³ 约 3,500 度
2 mm 272 L/min 142,963 m³ 约 14,100 度
4 mm 1,088 L/min 571,852 m³ 约 56,400 度

排查顺序建议这样走：先关掉所有用气支路，看母管压力能不能保住，判断是主管还是支路漏；再逐个车间听声、涂皂液或用超声波检漏仪定位；先处理接头与螺纹连接，最后才轮到拆气缸。这一轮往往不用换任何一个 O 型圈，只要把接头拧紧、老化软管换掉，漏气量就能降一大截。

七、给你的结论

气动 O 型圈记住四句话：

  1. 压力低就没有挤出风险，硬度往软走（60~80A 为主），别照搬液压的硬圈逻辑。
  2. 压缩率往区间上限取，拉伸率必须归零。液压圈拉 2%~4% 没事，气动圈拉伸就是漏。
  3. 气源里的油和水决定材质，且互斥：有油雾走 NBR / FKM，无油干燥走 PU / 内润滑 NBR，含水走 EPDM / PTFE，两头都占时只能选一侧。
  4. 漏气先查接头，再查气缸，静密封才是气动漏点的大头。

手上有工况温度、压力和一段气源描述，可以先用 选型工具 跑一遍：输入温度与介质，先筛出合法材质门类，再按密封形式给出压缩率与硬度推荐。如果卡在无油又要低露点这类两头都要的工况上，把空压机类型、干燥方式、实测露点与气缸动作频率发到 询单页，按实际气源条件给你配材质组合。

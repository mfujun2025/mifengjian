O 型圈材质选型速查表：按温度和介质三步定材质

2026-09-14　·　技术文章

选材质的正确顺序不是"先看温度"，而是先看介质。原因是：温度不够只会缩短寿命，介质不兼容会当场失效；而且介质这一刀切下去，能一次排除掉一半候选材质。

第一步：按介质做一次粗筛

只有三个问题要回答：

问题 1：接触矿物油系油品吗？（液压油、机油、齿轮油、汽油、柴油）

  • 是 → 从 NBR / HNBR / FKM / FVMQ / PU / CR 里选，排除 EPDM 和硅橡胶
  • 否 → 继续往下看

这是最关键的判断。EPDM 和硅橡胶在耐水、耐候、耐温上都很优秀，但遇矿物油必然溶胀。现场大部分"密封圈发胖挤出来"的事故，都是这两种材质用在了油系统上。

问题 2：接触的是哪一类特殊介质？

介质 只能用 绝对不能用
磷酸酯抗燃液压油 EPDM NBR（会被溶解）、FKM
醇醚型刹车油 DOT3/DOT4 EPDM NBR、FKM
热水 / 蒸汽 EPDM、专用蒸汽牌号 FKM（脱氟降解）、SI
酮类（丙酮/丁酮） EPDM、FFKM NBR、FKM、FVMQ、PU、CR
酯类溶剂 FFKM、PTFE NBR、FKM（低分子酯）、EPDM
芳香烃（苯/甲苯） FKM、FFKM、PTFE、FVMQ EPDM、NBR（长期）、CR
强碱 EPDM、FFKM、PTFE FKM、SI、NBR
氨 / 胺类 FFKM、PTFE FKM

问题 3：是户外或臭氧环境吗？

臭氧会让带双键的橡胶表面开裂。NBR 在这种环境下寿命很短，必须换 EPDM 或 HNBR。

第二步：按温度定材质档次

介质筛完之后，用长期工作温度（不是设备峰值温度）套下表：

温度区间 首选 备选 说明
-60 ~ -20 ℃ SI、FVMQ PTFE 包覆 可选材质极少，硅系是主力
-20 ~ 100 ℃ NBR HNBR、CR、PU 常规工业温区，丁腈性价比最优
100 ~ 150 ℃ HNBR FKM、EPDM（非油介质） 丁腈已到极限，必须升级
150 ~ 200 ℃ FKM SI、FVMQ（非油介质） 氟橡胶主场
200 ~ 300 ℃ FFKM PTFE 包覆 可选急剧收窄，成本大幅上升

一个必须强调的细节：不要用峰值温度选材质。设备偶尔冲到 130℃，不代表要用 150℃ 档的材质硬顶——如果 95% 的时间在 90℃ 运行，用 NBR 把余量留给寿命，比一开始就上氟橡胶更合理。反过来，如果长期 105℃ 运行，那 NBR 就是错的，哪怕峰值只有 110℃。

第三步：按成本收口

剩下的候选按价格从低到高筛：

NBR / EPDM / CR  <  SI / PU  <  HNBR  <  FKM / PTFE  <  FVMQ  <  FFKM

只要低档材质在介质、温度、压力三项上都满足，就不要往上跳。举个实际对比：

  • 工况：常温、矿物液压油、静密封 → 应该用 NBR，不需要 HNBR，更不需要 FKM。同样能密封十年，成本差 3~5 倍。
  • 工况：150℃、矿物液压油 → 必须 FKM。这时如果还报 NBR，不是省钱，是必然失效。

六个高频选型陷阱

1. EPDM 用在液压油上。 最常见的错误。EPDM 耐水耐候很优秀，看起来"更高级"，但遇矿物油会溶胀 30% 以上。

2. 硅橡胶用在液压系统上。 硅橡胶耐温 200℃ 很诱人，但耐矿物油性差，高温液压场合是双重打击。

3. FKM 用在水或蒸汽上。 氟橡胶"怕水不怕油"。把 FKM 用在蒸汽管路上，会脱氟降解——这种失效往往被误判为"买到了假货"。

4. 只看温度不看介质类别。 "液压油"要分清是矿物型、合成酯型还是磷酸酯型。三者对应的材质完全不同：矿物型用 NBR/FKM，酯型要评估，磷酸酯必须用 EPDM。

5. 忽略 PU 的水解问题。 聚氨酯耐磨抗挤出极好，但怕热水。潮湿环境温度稍高，PU 会发软、强度下降。

6. 忽略含油压缩空气。 气动系统如果气源除油不彻底，油雾会持续侵蚀 EPDM 圈，几个月后缓慢失效，很难定位原因。

快速自查流程

① 介质是矿物油系吗？
   是 → NBR/HNBR/FKM 家族，排除 EPDM、SI
   否 → ② 介质是水/蒸汽/醇/酮/酸碱/磷酸酯吗？
          是 → EPDM 优先，排除 FKM
          否 → ③ 介质是酮/酯/强溶剂吗？
                 是 → FFKM 或 PTFE
                 否 → ④ 按温度套表
② ③ 之后，再按温度套表定档次，最后按成本收口

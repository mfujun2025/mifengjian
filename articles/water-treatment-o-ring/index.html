水处理 O 型圈：耐氯与耐臭氧不是一回事

2026-10-09　·　技术文章

某污水厂加药间，计量泵的 O 型圈每两个月换一次：圈表面布满细密裂纹，手一掰就断，断面发白。介质是次氯酸钠，有效氯约 5%。维修工想不通——EPDM 不是号称耐臭氧、耐老化吗，牌号还是照着"耐水"那栏选的。同一座厂另一台加氯泵的圈三个月就溶胀成粗香肠，涨了近一成，用的是普通 NBR，供应商说"耐水、耐油"。

这两台泵的错是同一个：把"水"当成了介质。水处理里真正吃掉密封件的不是水，是加进去的氧化剂——余氯、次氯酸钠、臭氧。破坏方式还不一样：氯被吸收进基体、分子链断裂；臭氧是表面定向攻击。而"耐臭氧"这个词本身也不等于耐臭氧水，温度一升评级就掉。下面按浓度、温度、接触时间三个轴把选材分岔讲清楚。

一、水处理密封件的三个区段，介质完全不同

选材先定位：同一座水厂里，O 型圈面对的介质分三段，混着讨论必然出错。

区段 典型介质 温度 对密封件的主要威胁 首要材质方向
原水与清水段 河水、地下水、达标出水 5~40℃ 泥沙研磨、结冰 NBR / PU（静密封 EPDM）
加药与消毒段 次氯酸钠、液氯、臭氧、硫酸、氢氧化钠 20~80℃ 氧化剂侵蚀、酸碱腐蚀 按介质定 EPDM 或 FKM
出水与回用段 含余氯清水、消毒后水 20~35℃ 余氯长期作用、永久变形 EPDM（认证牌号）

真正的坑在第二、三段：加药间是短时间高浓度，出厂水是长时间低浓度。同一个 EPDM 牌号可能完全相反——短时间泡在浓氯里被咬出裂纹，长时间待在中低浓度余氯水里却在压缩永久变形上先失效。合并成一句"水处理用 EPDM"，等于没选。

二、耐氯：浓度和温度才是变量，不是"氯"

次氯酸钠是水处理最常见的消毒剂，也是打穿橡胶圈的首要原因。机理是氧化剂被吸收进橡胶基体，分子链断裂，材料溶胀、失去尺寸控制，计量泵阀球与阀座一旦失配就漏。判定只看三个数：有效氯浓度、温度、接触时间。经验边界是：低浓度常温氯水，普通 EPDM 表现良好；有效氯升到 10% 上下并连续投加就不再可靠——公开厂商案例里，12% 连续工况下 EPDM 密封件常在四到八周内溶胀失控，FKM 在同类工况下维持几何尺寸，寿命按"多年"计。

⚠️ 一个反直觉的点：耐氯与耐臭氧不能互相推断。臭氧和次氯酸钠是两种攻击方式，EPDM 抗次氯酸钠靠非极性主链不易被强氧化剂夺氢，不靠饱和结构抗氧化。

还有一个容易忽略的失效：EPDM 长期接触含氯水会表面发黑、水体发浊，即"墨汁现象"。三菱电缆公开数据可作参考——按 JIS K 6258 浸渍、次氯酸钠 500 ppm、80℃，标准 EPDM 配方数百小时即出现墨汁，耐氯专用配方 500 小时以上仍无异常。饮用水侧密封件一旦把水染黑，用户投诉的是水质不是密封件，要写进验收。

介质条件 普通 EPDM FKM 建议
余氯 1~5 ppm、常温长期 好（认证牌号） 不必要 EPDM
次氯酸钠 5% 左右、连续投加 一般，寿命以月计 好 连续段用 FKM
有效氯 ≥10%、连续 不可靠（溶胀失控） 可用 FKM 或 PTFE 包覆
氯气（气相） 劣化开裂 可用 高浓度氯气不走 EPDM
酸性次氯酸（pH 偏低） 风险叠加 需复核 单独选型

三、耐臭氧：耐臭氧 ≠ 耐臭氧水

EPDM 常年被夸的"耐臭氧"说的是臭氧气体。水处理里的臭氧溶在水里，最狠的位置是臭氧发生器出口——高浓度臭氧气 + 湿度 + 高温。

IPEX 公开的选择数据里，EPDM 对饱和臭氧水的评级在 20℃ 与 40℃ 是最优档，到 60℃ 降一档。即：常温低浓度臭氧水可用耐臭氧级 EPDM；温度或浓度一升，退到 FKM、FFKM、PTFE 或 PVDF。

臭氧工况 材质方向 说明
臭氧水、常温、低浓度 耐臭氧级 EPDM 可用 需按牌号与停留时间复核
臭氧水、40℃ 以上或长期滞留 FKM / FFKM / PTFE 包覆 EPDM 评级随温度降
臭氧气、干燥 EPDM / FKM 可评估 气相臭氧对饱和橡胶友好
臭氧发生器出口（湿热高浓） FKM / FFKM / PTFE / PVDF 全厂最严苛位置之一
臭氧管路阀门密封面 PTFE 球与座 阀球阀座需分别确认

还有一条常被跳过：臭氧会把 NBR 吃掉。丁腈双键含量高，臭氧顺着双键断链，这是站内材质库明确标出的禁区。臭氧设备区若沿用 NBR 静密封位，开裂只是时间问题。

四、加药间里 EPDM 与 FKM 会反向失效

加药间最狠的一处，是强碱与强氧化剂同时存在：pH 用氢氧化钠调，消毒用次氯酸钠——两者恰好是 EPDM 和 FKM 各自的软肋。

介质 EPDM FKM 别踩的坑
氢氧化钠（强碱） 好 不耐，会被侵蚀 FKM 在加药间最常见的误用
次氯酸钠、浓氯 边界受限 好 见第二节
臭氧水 常温可用，高温降级 好 见第三节
热水/蒸汽（清洗、伴热） 好 不耐热水蒸汽 有蒸汽的管路会被脱氟降解
矿物油（泵轴承、齿轮箱侧） 绝不耐，见油即废 好 耐水又沾机油时材质没有全解
聚氨酯（耐磨动密封） — — 会水解，热水与加药间里 PU 出局

三条红线与站内材质库同一口径：EPDM 绝不耐矿物油；FKM 不耐强碱、不耐热水蒸汽；NBR 不耐臭氧、不耐酮酯类。加药间若碱与矿物油并存，正确做法不是找"全兼容"橡胶，而是把密封位按介质拆开——湿侧用 EPDM 或 FKM，传动侧、油腔侧走另一套。

五、泵阀：先分清密封位在哪一侧

泵阀上的 O 型圈多数不在泵腔最湿处，而在阀座、阀盖、填料压盖、机械密封腔的静密封位，失效方式不是"泡坏"，而是失去压紧力 + 颗粒磨损。

密封位 主要失效方式 对材质的要求 典型建议
球阀/蝶阀阀座 介质腐蚀 + 阀球座失配 耐介质优先 涉氯段用 PTFE 座，勿用 EPDM
机械密封腔（静密封 O 圈） 压缩永久变形 + 冲洗液溶胀 耐冲洗液 EPDM（水冲洗）/ FKM（油冲洗）
泵壳体法兰静密封 螺栓预紧衰减、热循环 抗永久变形 EPDM 或按温度升 FKM
填料压盖 摩擦磨损 耐磨 PU（冷水）/ FKM 热水
加药计量泵阀球座 溶胀失配、计量漂移 尺寸稳定、耐氧化剂 FKM / PTFE

机械密封的冲洗方案直接决定密封圈泡在什么介质里。按 API 610 / API 682 的 Plan 编号：11 / 13 用泵自身介质回流到密封腔；21 / 23 加冷却器；31 经旋风分离器把清洁液送密封腔、固体回吸入侧；32 从外部供入清洁液；62 在大气侧冲淋。两个要点：Plan 31 的旋风分离器只对足够重的固体有效，絮体细砂分离不掉；Plan 32 的外供液会接触密封腔，加药间用什么液必须跟密封件一起定，不能默认用水。

六、饮用水侧还有一层硬要求

饮用水和污水不是一套验收标准：饮用水侧的密封件除了耐介质，还要不向水体迁移有害物质，这条由认证管，不由材质表管。

  • NSF/ANSI/CAN 61：饮用水系统部件健康效应，明确覆盖垫片与密封材料，管的是迁移与萃取物；
  • NSF/ANSI/CAN 372：饮用水接触件无铅要求；
  • AWWA C111/A21.11：球墨铸铁压力管道与配件的橡胶垫片接头，规定型式、等级与检验，很多 EPDM 垫片牌号按其 Table 4 定级；
  • 材料标识常见按 ASTM D2000 分类号给出（如 M5CA810 A25 B35 C32 EA14 F17 Z1，末位 Z1 即 75±5 邵氏 A），压缩永久变形按 ASTM D1330 评。

三条采购动作：① 报价单写清牌号是否同时具备 NSF/ANSI 61 与 AWWA C111 引用，只写"食品级"不算数；② 索要压缩永久变形数据（温度与时间写明），这是长周期静密封的寿命主导指标；③ 饮用水侧要过氧化物硫化、无填料迁移的专用牌号，普通 EPDM 胶料不等于饮用水级。

七、直接照着做的判断顺序

  1. 先定位密封位在哪一段：原水清水、加药消毒、还是出水回用。
  2. 再问介质是不是"水"：有次氯酸钠、臭氧、氢氧化钠、硫酸的段位，按第二节查浓度档。
  3. 把浓度×温度×接触时间写进询价单，让供应商按数据表回答"这个浓度、这个温度用哪种材质"，而不是回答"耐不耐水"。
  4. 用站内工具做初筛：O 型圈材质选型工具 可按温度与介质推荐。⚠️ 它的介质库只有通用介质，没有余氯、次氯酸钠、臭氧水三项——需借最接近的项：低浓度余氯按"水（常温）"、臭氧按"空气/臭氧"、氢氧化钠按"强碱"，真正的判断变量仍是浓度、温度与时间，工具给的是初筛不是结论。
  5. 泵阀同步确认冲洗方案：密封腔里流的是 Plan 11 的回流液还是 Plan 32 的外供液，材质跟着那一股液定。
  6. 饮用水侧补认证：NSF/ANSI/CAN 61 与 AWWA C111 引用、压缩永久变形数据，两项缺一不采购。
  7. 换件时把旧圈留着：次氯酸钠段看断面是否发白、是否溶胀，出水段看体积变化与永久变形——两种痕迹原因完全不同。

材质拿不准、或手上只有一个旧圈想反推规格，把尺寸、介质、温度发到询单页，我们按站内材质库口径给建议；尺寸与匹配度先用规格查询工具 查一遍。

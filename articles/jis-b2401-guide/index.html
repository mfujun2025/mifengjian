JIS B 2401 编号怎么读：日标 O 型圈换件指南

2026-09-28　·　技术文章

同一台日系设备的两处密封位，图纸上一处标 G25，另一处标 25×3.55 G。采购都按「JIS G 系列」下单，结果一个装不上，另一个装上了还是渗。

问题不在数字，在 JIS B 2401 里本来就有两套东西都叫 G——一套是前缀，一套是后缀。把它们当成同一个系列，是日系设备换件最常见的一次翻车。

一、三套并行的编号体系，字母撞了两次

JIS B 2401 现行版是 2012 年拆成的四部分：-1 O 型圈尺寸、-2 沟槽尺寸、-3 外观质量验收、-4 挡圈（支承环）。其中尺寸部分同时装着三套编号，合计约 1006 个规格：

编号写法 体系 例子 实物尺寸（内径 × 截面，mm） 与国标的关系
前缀 ＋ 数字 JIS 传统系列（194 规格） G25 24.4 × 3.10 国标无对应件
前缀 ＋ 数字 同上 P22 21.8 × 2.40 需逐项核算
前缀 ＋ 数字 同上 V100 99.0 × 4.00 国标无这一支
尺寸 ＋ 后缀 G ISO 一般工业用（445 规格） 25×3.55 G 25.0 × 3.55 与 GB/T 3452.1 一致
尺寸 ＋ 后缀 A ISO 航空及精密机械用（367 规格） 尺寸自成一表 — 与国标不对应

前缀 G 与后缀 G 差了整整一档：G25 是 24.4 × 3.10，25×3.55 G 是 25.0 × 3.55。内径差 0.6 mm、截面差 0.45 mm，两个差距都远超各自的公差带，装不进同一个沟槽。

所以看到「JIS 规格表」，第一句要问的是：哪一套。

2012 年这次改版还并掉了三个独立的老标准。老图纸上引用到它们，不必再去另找：

老图纸上的引用 现行位置 内容
JIS B 2401:1991 / 1999 / 2005 JIS B 2401-1:2012 O 型圈尺寸与公差
JIS B 2406:1991 JIS B 2401-2:2012 沟槽（安装槽）尺寸
JIS B 2408:2005 JIS B 2401-3:2012 外观质量验收，对应 ISO 3601-3
JIS B 2407:1995 JIS B 2401-4:2012 挡圈 / 支承环，对应 ISO 3601-4

也就是说，日标不只规定 O 型圈的尺寸，还自带沟槽标准、外观验收标准和挡圈标准。这正是日系设备的沟槽常常对不上国标沟槽表的原因——它按的是 JIS B 2401-2 那一套，而国标沟槽在 GB/T 3452.3 里。

二、前缀 P / G / V / S：分工与截面档

传统系列用前缀区分用途，截面档和尺寸覆盖都不同：

前缀 用途 截面档（mm） 内径覆盖（mm）
P 运动密封（活塞、活塞杆） 1.90 / 2.40 / 3.50 / 5.70 / 8.40 2.8 ~ 399.5
G 固定密封（端面、法兰） 3.10 / 5.70 19.4 ~ 909.3
V 真空法兰 4.00 / 6.00 / 10.00 14.5 ~ 1044
S 小截面（厂商扩展，JIS 未正式收入） 1.50 / 2.00 2.5 ~ 149.5

最容易被忽略的是 P 与 G 之间不能互替——这一点比「JIS 不能替国标」更隐蔽，因为两个系列的内径是接得上的。看内径 24 mm 附近：P24 是 23.7 × 3.50，G25 是 24.4 × 3.10。内径只差 0.7 mm，截面差了 0.4 mm，沟槽深要跟着差 0.4 mm，是两种完全不同的件。

三、编号不是内径，实物要小 0.2~0.7 mm

这是 JIS 编号最实用、也最常被当成内径报价的一点：

编号 实物内径（mm） 截面（mm） 计算外径（mm） 编号 − 内径
P10 9.80 1.90 13.60 0.20
P10A 9.80 2.40 14.60 0.20
P22 21.80 2.40 26.60 0.20
P22A 21.70 3.50 28.70 0.30
P50 49.70 3.50 56.70 0.30
P100 99.60 5.70 111.00 0.40
P200 199.50 8.40 216.30 0.50
G25 24.40 3.10 30.60 0.60
G100 99.40 3.10 105.60 0.60
G200 199.30 5.70 210.70 0.70
V100 99.00 4.00 107.00 1.00
V175 173.00 4.00 181.00 2.00
V480 475.00 10.00 495.00 5.00

规律很清楚：截面越粗，编号与实物内径的差越大。P 系列从 0.2 mm（截面 1.9 / 2.4）递增到 0.5 mm（截面 8.4），G 系列是 0.6 / 0.7 mm，V 系列更夸张（V480 差 5 mm）。拿图纸编号直接当内径去报价，必错。

带小数的编号（P11.2、P12.5、P22.4、P29.5）是细分号，不是公差标注；把 P12 和 P12.5 当同一个件，是这一档最常见的低级错误。

还有一条：字母 A 后缀 = 内径不变、截面加大一档。P10 是 9.8 × 1.90，P10A 是 9.8 × 2.40；P22 是 21.8 × 2.40，P22A 是 21.7 × 3.50。同一个内径配两种截面，分别对应轻载与高压。订货时后缀掉了，等于订错件。

四、材质记号：图纸上写的不是 NBR，是「1 种 A」

日系图纸和铭牌的材料栏通常写 1种A、4种D 这类记号，不写 NBR、FKM。对照关系如下：

材料记号 胶种 硬度 典型定位
1 种 A NBR 系 70 耐矿物油，通用默认件
1 种 B NBR 系 90 耐矿物油，高压抗挤出
2 种 NBR 系 70 耐汽油、轻柴油等燃料油
3 种 SBR 或 EPDM 70 耐动植物油、耐水汽
4 种 C VMQ 硅橡胶 70 耐热耐寒，-60 ~ 200℃
4 种 D FKM 氟橡胶 70 耐热耐油主力，-20 ~ 200℃

三条不能越过的边界：

  • 2 种叫「耐汽油」，但它仍是丁腈系。 丁腈不耐臭氧、不耐酮酯，遇醇醚型刹车油会溶胀。不要因为「耐汽油」三个字就把它推进刹车系统或强溶剂场合。
  • 4 种 C 是硅橡胶，耐热耐寒却不耐矿物油。 液压油、机油、齿轮油环境下一律不能用 4C。把「4 种 C 耐热」直接理解成能用在液压位，是日系设备里最容易出事故的一条误读。
  • 3 种若供方给的是 EPDM 配方，绝对不能碰矿物油；即便是 SBR 配方，耐矿物油也远不及 1 种 A。这一档的正确位置是水、蒸汽、醇类与动植物油。

另外提一句：网上和部分海外供应商的对照表把 2 种写成 FKM、4 种 D 写成 EPDM，与 JIS 原文相反。下单时同时给「材料记号 ＋ 供方胶料代号」，不要只给记号。

五、V 系列：换的是法兰槽，不是 O 型圈

真空法兰用的 V 系列，编号逻辑和 P / G 完全不同——V 后面的数字是法兰沟槽的公称内径（依据 JIS B 2290），不是圈的内径：

编号 圈内径（mm） 截面（mm） 法兰槽内径 G1（mm） G1 公差 槽宽 S（mm） 槽深 G（mm）
V15 14.5 4.0 15 +1.0 / 0 5.0 3.0
V40 39.5 4.0 40 +1.0 / 0 5.0 3.0
V100 99.0 4.0 100 +1.0 / 0 5.0 3.0
V175 173.0 4.0 175 +1.0 / 0 5.0 3.0
V225 222.5 6.0 225 +1.5 / 0 8.0 4.5
V430 425.5 6.0 430 +1.5 / 0 8.0 4.5
V480 475.0 10.0 480 +2.0 / 0 12.0 7.0
V1055 1044.0 10.0 1055 +2.0 / 0 12.0 7.0

注意沟槽公差的方向：G1 全是正公差（+1.0 / 0、+1.5 / 0、+2.0 / 0），没有负向余量。这类槽是车出来的，槽偏大一点，圈还能靠压缩补上；槽偏小就直接装不进去，所以公差只给正方向。

现场遇到真空漏，先量法兰槽的内径与槽深，再量圈。V 编号指的是槽，同一张图纸上圈内径（V100 → 99.0）和槽内径（100）差 1 mm，很容易看错。

六、日系设备换件的判断顺序

  1. 先认字母位置：是前缀（P / G / V / S）还是后缀（… G / … A）。后缀 G 可以直对国标，前缀 G 不能。
  2. 把编号还原成实测尺寸：按第三节的表换算出内径与截面，不要拿编号当内径。
  3. 查材料记号：重点确认 4 种 C（硅胶）没有用在油里、2 种（丁腈系）没有用在臭氧或刹车油环境。
  4. 查沟槽按哪一套：JIS 的沟槽尺寸在 B 2401-2，国标的沟槽在 GB/T 3452.3。换件时沟槽不动，所以要按沟槽反推该配哪个截面，而不是照抄旧圈的标称值。
  5. 按最小截面核算压缩率，再实测：压缩率 W =（截面 − 沟槽深）÷ 截面。

第 5 步为什么是决定性的，看一个可复算的例子。沟槽按 JIS P10（截面 1.90）设计，静态径向密封取 18% 压缩率，则沟槽深 = 1.90 ×（1 − 18%）= 1.558 mm。现在用国标件替：

代用件 实际截面（mm） 计算压缩率 判断
JIS P10 原厂 1.90（标称） 18.0% 设计值
GB 9.75 × 1.8 1.80（标称） 13.4% 低于静态径向 15%~20% 下限
GB 9.75 × 1.8 1.72（走下差） 9.4% 明显不足，低压就渗
GB 9.75 × 1.8 1.88（走上差） 17.1% 可用

内径 9.75 对 9.8，差 0.05 mm，几乎无感；截面差 0.1 mm 听起来也不大。但压缩率必须按最小截面算：只看标称值，压缩率就从 18% 掉到 13.4%，走下差只剩 9.4%，已经跌出静态径向 15%~20% 这个推荐区间。

所以「截面差 0.1 mm 可以评估」这句话的准确落点是：可以评估，但得按最小截面核算，不能按标称算。

反过来，25×3.55 G 这类后缀 G 的日标件，对国标 25×3.55 是尺寸与公差都一致的——GB/T 3452.1-2005 等同采用 ISO 3601-1，1.8 / 2.65 / 3.55 / 5.3 / 7.0 五个截面档与内径优先数系完全相同。这一类可以直接采购，不必换算。

七、三句话记住 JIS

  • 前缀与后缀是两套东西：G25 不等于「25 的 G 系列」，真正对得上国标的是 25×3.55 G。
  • 数字不是内径：P / G / V 的编号是内径公称值，实物内径小 0.2~0.7 mm，V 系列差得更多。
  • 材质记号先看红线：4 种 C（硅胶）不碰油，2 种（丁腈系）不碰臭氧与刹车油，3 种（SBR / EPDM）不碰矿物油。

需要按内径或截面反查规格、核对公差时，用站内的 O 型圈规格查询工具；手上只有旧圈的实测尺寸、没有型号时，用近似匹配输入实测值看候选规格与偏差；材质拿不准是否与介质相容，也可在工具页按温度和介质查推荐材质。整台设备的密封件要打包换件，把图纸标号或实物尺寸整理好发到询单页，可以一次核对完。

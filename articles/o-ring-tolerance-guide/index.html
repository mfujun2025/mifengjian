O 型圈尺寸公差与检验：哪些尺寸必须量、怎么量

2026-09-30　·　技术文章

一批 1.8 mm 截面的圈，甲方抽检 30 件，卡尺读数最小 1.72、最大 1.88；供方用自己的投影仪复测同一批，读到 1.74 到 1.86。两边都不算错，GB/T 3452.1 给 1.8 截面写的公差是 ±0.08，18 件读数全都落在合格带里——可如果甲方判退的判据写的是"卡尺读数不得低于 1.75"，这批货就是不合格品，供方拿自己的数据申诉也翻不了案。

这类争议几乎每周都在发生，根源不在产品，在验收动作没有定义清楚：用什么量具、量哪个尺寸、抽多少件、判定门槛是多少。前几篇讲过公差"是多少"，本篇只讲"怎么量、怎么判"。

一、先定优先级：截面 > 内径 > 外径

验收时间有限，必须知道哪个尺寸错了代价最大——截面错了整批报废，内径偏了改沟槽还能救。排序如下：

尺寸 地位 错了会怎样 抽检强度
截面直径 d2 关键尺寸 压缩率的分母，偏一点压缩率就整体漂移 每批必测，多点取中位数
内径 d1 重要尺寸 影响拉伸率与装配，超差表现为"装不上" 每批必测
外径 d3 推导尺寸 等于 d1 + 2×d2 不单独判定
圆度 / 椭圆度 过程指标 超差说明模具或硫化不稳 精密件测

外径不是一个独立受控尺寸。 国标只规定内径与截面这两个基量，外径是算出来的（d3 = d1 + 2 × d2）。所以"量外径对不上号"不能作为判退理由，它只能提示你前两个尺寸里至少有一个不对。

二、量具选型：不同量法能差出 0.08 mm

O 型圈是弹性体，任何接触式测量都会把圈压变形，读数必然偏小。量具的选择本质上是在"效率"和"不施加测量力"之间取舍。

量具 测什么 测量力影响 相对偏差量级 适用场景
游标 / 带表卡尺 内径、外径 大，靠手感控制 可达 0.05~0.10 mm，受压越软偏差越大 现场粗筛，不作判定依据
锥形量规（锥规） 内径 极低，靠自重力落位 优于卡尺，重复性好 车间推荐的常规内径检具
光学投影仪 / 工具显微镜 内径、截面 零（非接触） 可达 ±0.01 mm 小规格、精密件、争议复测
激光测径仪 截面 零 与非接触法一致 批量截面筛查
切片投影 截面 零，但破坏样品 与投影法同级 争议仲裁、首件确认

三条实战经验，直接决定你量出来的数字可不可信：

第一，卡尺读数系统性偏小。 橡胶受压变形，两爪一夹截面就矮了，硬度越低偏得越多。卡尺读出的 1.72（标称 1.8）看似「走下差」，实际可能只是被夹扁。

第二，锥规测内径比投影仪更准更快。 这与直觉相反——投影仪精度虽高，但O 型圈自由状态下并不圆（椭圆、轻微波浪），在屏幕上量三条均布直径取平均反而放大误差，大规格件尤甚。锥规靠圈自身张力自然落位，一致性更好。

第三，切片投影与直立反射光测量有系统性差值。 圈竖直固定在工具显微镜上用反射光量轴向线径，读数比切片投影小 0.05~0.10 mm；测径向线径时两种方法无明显差异。所以争议复测必须先在双方约定同一种方法。GB/T 3452.2-2007 也写明：发生争议时测量方法应由制造商与用户协商确定。

环境温度同样是变量。 橡胶线膨胀量级在 0.02%~0.05%，标准测量环境为 23±2℃。刚从冷库或热机拆下的圈直接量，量到的是温度。

三、抽多少件：把"量几个"换成抽样方案

凭经验抽 3 件、5 件最容易出事——样品量太少，3% 的不合格率极大概率被漏掉。正规做法走 GB/T 2828.1-2012（等同采用 ISO 2859-1）的计数抽样：

  1. 定批量 N 和检验水平。无特殊要求用一般检验水平 II；判别力要求高、检验成本低用水平 III；检验具破坏性（如切片投影）用水平 I 或特殊水平 S-1~S-4。
  2. 定 AQL。按缺陷严重程度分档：致命缺陷（裂纹、缺料、穿刺）取 0.10~0.15；主要缺陷（截面、内径超差）取 1.0~1.5；次要缺陷（轻微毛边、色差）取 4.0~6.5。
  3. 查样本量字码，再查抽样方案，读出样本量 n 与接收数 Ac、拒收数 Re；遇箭头沿箭头方向取第一组数值。
  4. 判定：不合格品数 d ≤ Ac 接收整批；d ≥ Re（一般 Re = Ac+1）拒收。
批量 N 检验水平 字码 样本量 n AQL=1.0 时 Ac / Re
151~280 II G 32 1 / 2
281~500 II H 50 1 / 2
501~1200 II J 80 2 / 3
1201~3200 II K 125 3 / 4

注意字码 H 那一行：抽 50 件，允收 1 件、第 2 件就拒收整批。这就是"抽 5 件全合格就放行"和正规抽样之间的差距——前者的实际风险远高于直觉。以上为一次正常检验的典型值，正式检验请以 GB/T 2828.1 现行标准表为准。

四、判定门槛：三档口径必须写死

最容易埋雷的地方是判定口径模糊。"符合 GB/T 3452.1"这句话在争议时毫无约束力。实际要落到三档之一：

标称值口径（标称 1.8 ±0.08，实测落在 1.72~1.88 即合格）最宽松，允许压缩率波动；公差带口径（实测值须落在标准公差带内）是常规验收默认用的一档；功能窗口口径（实测压缩率须落在推荐区间内）最严，要先确定沟槽深度，用于高压、动密封与精密件。

第二档与第三档的区别要看一个实算：沟槽深 1.52 mm、圈标称 1.8（公差 ±0.08）。

实测截面 压缩率 静态径向（15%~20%）判定
1.72（下差极限） 11.6% 不合格：低于窗口
1.78 14.6% 不合格：仍略低于窗口
1.80（标称） 15.6% 合格：刚进窗口
1.88（上差极限） 19.1% 合格

结论很直接：这一批圈即使 100% 落在公差带里，也可能大半不合格。 原因是沟槽深度按标称截面设计时，把全部公差余量都让给了「偏小」的一侧。所以高压、动密封场合不能用公差带口径验收，必须换算成压缩率窗口——沟槽深度先定下来，反推截面允许的实测范围。换算用规格查询工具输入尺寸与沟槽深即可看到压缩率。

五、外观与硬度：两项容易漏掉的验收动作

外观依据 GB/T 3452.2-2007（等同采用 ISO 3601-3:2005），分 N、S、CS 三级，越往后越严：N 级用于一般工业，S 级用于汽车与精密装配，CS 级用于航天军工与生命安全场合。采购未规定等级时默认按 N 级；特定航空航天应用按 S 级。

判定规则里有三条硬口径值得记住：

  • 观察条件：自然状态下、适当灯光下用 2 倍放大镜观察，表面不得有超过限值的裂纹、破裂、气泡或其他缺陷。
  • 数量限制：限值内的流痕、缺料、凹痕，N 级与 S 级在圆周上任意 25 mm 长度内不得超过 3 处；CS 级不得超过 1 处，且缺陷之间不允许相互连接。
  • 杂质零容忍：上述观察条件下，圈表面不允许嵌入外来杂质。硬质或金属夹杂在动密封里等于砂纸。

一级拒收项不用量：裂纹、切口或撕裂、缺料、气泡（真空与动密封场合）、硬质夹杂、密封接触面上任何缺陷。可控项里，错位与毛边的限值按截面直径分档，截面越大限值越宽。

硬度依据 GB/T 531.1（对应 ISO 7619-1），三个动作最关键：试样厚度需 ≥6 mm，不足时叠层但最多三层且层间无空气间隙；压针接触后 1 秒内读数；每试样测 5 点取中位数，测点距边缘 ≥12 mm、相邻测点间距 ≥6 mm。胶料硬度公差常规为标称 ±5，单点读数不能作为判退依据；2 mm 级薄截面件直接上邵氏 A 读数偏高 5~10 度，只可作过程筛查。

六、来料验收的六步固定动作

把上面的内容压成一张可执行的清单，可直接贴到检验台上：

  1. 先看外观，后量尺寸。 裂纹、缺料、硬质夹杂一旦发现直接判退，不必再花时间量。
  2. 看包装与标识。 规格标识应含内径 d1、截面 d2、系列代号（G 或 A）、等级代号（N 或 S）。标识不全先挂起，不要先入库。
  3. 在 23±2℃ 环境下调节后测量。 低温件与热机拆下的旧件必须先回温。
  4. 截面用非接触法或锥规定位后测，多点取中位数。 不用卡尺读数直接判退；有争议改用切片投影，在双方约定的同一方法下复测。
  5. 按 GB/T 2828.1 抽样判定，AQL 按缺陷分档取值。 截面与内径走主要缺陷的 AQL；高压动密封件再补做压缩率窗口核算。
  6. 高要求场合加做压缩永久变形。 依据 GB/T 7759.1-2015（等同 ISO 815-1），常用条件为 25% 压缩率下 70℃×22h 或 100℃×70h，需在采购规格里写明条件与上限。

七、采购规格书要写的四行

争议的根子几乎都在采购单上。以下四行写全，验收时就不会各说各话：

1. 尺寸：内径 d1 × 截面 d2，依 GB/T 3452.1-2005 G 系列，注明公差
2. 外观：依 GB/T 3452.2-2007，等级 N（S / CS 按需）
3. 材质与硬度：牌号 + 硬度值及公差（如 FKM 70 ±5 Shore A）
4. 验收方法：量具（锥规 / 投影仪）、抽样标准（GB/T 2828.1，检验水平 II，AQL 分档）、
   检测环境（23±2℃）、争议复测方法

其中第 4 行最常被省略，也最容易出问题。只写"符合国标"等于什么都没写：国标给了公差带，却没规定用卡尺还是投影仪、抽 5 件还是 50 件、争议听谁的。

选材质与温度、介质是否匹配，用材质推荐过一遍；要打样、打小批或需要供方确认验收方案，走询单页，把规格、材质、硬度、数量连同上述四项验收要求一次给全，比来回确认省事。

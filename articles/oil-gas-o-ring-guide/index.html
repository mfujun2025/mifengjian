石油天然气设备密封件：H2S 分压决定材质，压力决定硬度

2026-10-13　·　技术文章

一份井下工具的采购单上写着：材质 FKM，耐温 200℃，耐压 70 MPa。温度对得上，压力对得上，装上井三个月后失效。密封圈不是被压坏的，是从内部被撑裂的——外观完好，剖开断面全是细密裂纹。耐高压、耐 H2S、耐快速泄压是三种独立的能力，而采购单上通常只写了第一种。

一、油气密封的难点：四条约束同时压下来

井口与管线的压力等级按 API 6A 分 2000 至 15000 psi 五档，最高一档约 103 MPa；温度等级从 K（-60~82℃）排到 Y（-18~343℃）。密封件面对的也不是单一介质，而是烃、水、H2S、CO2 的多相混合物。四条约束会同时落到同一个密封件上：

  1. 化学侵蚀——H2S、CO2 在含水条件下攻击分子链；
  2. 快速泄压——高压气体溶入橡胶，泄压时在内部膨胀；
  3. 挤出——百兆帕级压差把软材料挤进沟槽间隙；
  4. 温度跨度——寒区 -40℃ 启动与井下 150℃ 持续，常需同一材质覆盖。

最常见的失误，是把温度和压力填完就下单，弹性体一栏只写"FKM"——上面四条，它一条都没回答。

二、H2S 的门槛不看浓度，看分压

判断一个工况是否属于酸性环境（sour service），依据是 H2S 的分压，不是浓度。GB/T 20972（等同或修改采用 ISO 15156，即 NACE MR0175）的判据是：H2S 分压 ≥ 0.3 kPa（0.05 psia），且存在液相水。分压 = 系统总压 × H2S 体积分数，所以压力越高，触发门槛所需的浓度越低：

系统压力 达到 pH2S = 0.05 psia 所需的 H2S 体积分数
2000 psi（约 13.8 MPa） 约 25 ppm
5000 psi（约 34.5 MPa） 约 10 ppm
10000 psi（约 68.9 MPa） 约 5 ppm
15000 psi（约 103 MPa） 约 3.4 ppm

所以当有人用"我们的气很干净，H2S 才几十个 ppm"来判断工况时，如果井口压力是 15000 psi，这点 H2S 早已远超门槛——压力会替你放大 H2S 的杀伤力。

标准体系还要分清：GB/T 20972 / ISO 15156 管的是金属材料的开裂（硫化物应力开裂 SSC、应力腐蚀开裂 SCC 与氢致开裂 HIC），碳钢硬度上限 22 HRC；弹性体不在它的覆盖范围内，走的是 ISO 23936-2、NORSOK M-710、NACE TM0297 与 TM0192。一个高频错误是采购单写"要 NACE 认证的 O 型圈"——弹性体没有"NACE 证书"，只有具体牌号的 RGD 试验报告。

三、爆炸减压：外观完好、内部开裂的那种失效

高压下橡胶不是把气体"隔开"，而是会吸进去。压力越高、时间越长，CH4、CO2、H2S 就溶入并扩散到材料内部；此时若系统快速泄压，外部压力瞬间降低，内部溶解的气体来不及扩散出来，就地膨胀，应力一旦超过材料内聚强度，就从内部形成空腔与裂纹。这种失效叫爆炸减压（ED），也叫快速气体减压（RGD）。特征是表面往往完好，剖开断面才看得到裂纹——若只按外观判断"圈没坏、是安装问题"，方向从一开始就错了。

CO2 在橡胶中的溶解度显著高于其他气体，膨胀比大；H2S 在多循环试验中破坏性最强——同一批氢化丁腈试样在纯甲烷中十次循环后评级仍为 0 级，换成含 25% H2S 的混合气后多数出现可见裂纹。

业界用三套试验判定弹性体的抗 RGD 能力：

项目 ISO 23936-2 NORSOK M-710 NACE TM0297 / TM0192
试验气体 10:90 CO2:CH4 10:90 CO2:CH4 >99% CO2
温度 100℃ 100 / 150 / 200℃ 50~230℃（TM0192 为常温）
压力 150 bar（15 MPa） 100 bar 7~38 MPa（TM0192 为 5.2 MPa）
循环 10 次升压-泄压 10 次 单次浸泡 24 h
泄压速率 按标准剖面 20~40 bar/min —
结果判读 剖切后评级 0~5 级（0 为无损伤） 与 ISO 同口径 外观与内部评级 1~4 级

"某牌号通过 NORSOK M-710"，等于说它在 100~200℃、100 bar 的 CO2/CH4 混合气下、十个循环后剖切未见超标损伤——这和"耐温 200℃"完全是两个层面的信息。

对策三条，按性价比排序：控制泄压速率——不花钱，把放压时间从几分钟延到几十分钟风险就明显下降，也是现场唯一能自己做的动作；提高沟槽填充率——两套标准本身就把密封件占沟槽体积的比例规定在 80%~85%，同样的材料装在填充率合理的槽里，RGD 评级通常好一档；选抗 RGD 牌号并加挡圈，见第四、五节。

四、材质清单：谁进得了酸性气井

先给一张可直接对照的总表，再逐个说边界。表中温度区间与本站工具页 /tool/ 的口径一致。

材质 温度区间 耐 H2S / 酸性气 耐烃（原油、凝析油） 耐胺液 / 蒸汽 抗 RGD 相对成本 油气典型位置
NBR -30~100℃ 差 优 差 差 1 常温无硫原油输送、低压燃气法兰
HNBR -40~150℃（峰值 165℃） 良~优 优 一般 良（须过氧化物硫化） 2~4 含硫集输管线、井下封隔器、井口密封
FKM -20~200℃ 中 优 差 良 高 无硫高温油气、炼化高温管线
FEPM（AFLAS） 约 -10~200℃ 优 一般 优 良~优 5~10 脱硫胺液装置、稠油热采

NBR：在酸性工况里是一票否决。 站内口径 -30~100℃。分子链保留了大量双键，H2S 与臭氧都直接攻击双键，部分阀门与管件规范实际把 NBR 限制在非酸性的 0 区。常温无硫原油输送、低压燃气法兰可以用，含硫集输管线不要用。

HNBR：油气的绝对主力。 站内口径 -40~150℃（峰值 165℃）。加氢把双键饱和后，耐 H2S、耐胺类缓蚀剂、耐臭氧全面改善，同时保留耐烃能力——这是它能同时补上"NBR 不耐硫"和"EPDM 不耐油"的原因。采购必须写清：只有过氧化物硫化的 HNBR 抗 RGD 才好，只写"HNBR"不够，要写到"过氧化物硫化 + 90 Shore A + 抗 RGD"。

FKM：高温耐烃的答案，不是酸性气井的答案。 站内口径 -20~200℃，耐矿物油、原油与芳烃，气体渗透率低，是无硫高温管线的好选择。两条边界：分子链含偏氟乙烯单元，在热水、蒸汽、胺类和强碱下会脱氟降解，而脱硫装置里恰好同时有胺液和 H2S；低温下限约 -20℃，寒区启动不够用。

FEPM（四丙氟橡胶，AFLAS 是常见商品名）：专门补 FKM 的那个位。 工具页收录的 10 种材质里没有它，但油气现场绕不开。它由四氟乙烯与丙烯共聚，分子链上没有偏氟乙烯单元，不会脱氟，耐胺、耐碱、耐蒸汽、耐 H2S 都明显优于 FKM，连续使用约 -10~200℃。代价三处：低温柔性差（约 -10℃）、不耐芳烃与酮类、价格通常是 FKM 的 2~5 倍。脱硫胺液装置与稠油热采是它最典型的两个位置。

FFKM：能力天花板，但不是"选了就赢"。 站内口径 -20~300℃，几乎耐所有介质。但同为 FFKM，普通牌号抗 RGD 并不好，要选标注 AED（抗爆炸减压）并有 NORSOK M-710 或 NACE TM0297 报告的牌号。价格通常是 FKM 的十倍以上，只用在深井、海底和不能停机检修的关键密封上才划得来。

EPDM 与硅橡胶：两条不能碰的红线。 共同点是耐候、耐臭氧、耐水；共同短板是都不耐矿物油与烃类——站内工具页 /tool/ 对两者在机油、原油、汽油上的判定均为不兼容。油气只要存在凝析油或原油液相，这两种直接出局。寒区井口外露件、伴热蒸汽侧可以考虑 EPDM，但先确认介质里没有油。

PTFE 与弹簧蓄能密封：没有弹性，反而是优势。 纯 PTFE 无弹性、会冷流，做静密封要配合弹簧蓄能结构或挡圈；但也正因为是塑料、气体基本不溶入，天然不存在 RGD 问题。高压阀门、频繁启闭球阀与深冷场合用它比任何弹性体都稳，站内口径 -60~260℃。

五、压力只决定两件事：硬度和挡圈

"耐压 70 MPa"不是一种材质属性。高压带来的失效是挤出：软材料在压差作用下被挤入沟槽与配合面之间的间隙，边缘被切掉一块，密封随即失效。调节杠杆只有三个——间隙、硬度、挡圈。

系统压力 70 Shore A 允许径向间隙 90 Shore A 允许径向间隙
≤ 5 MPa（约 700 psi） ≤ 0.15 mm ≤ 0.25 mm
5~10 MPa ≤ 0.08 mm，或加挡圈 ≤ 0.13 mm
> 10 MPa（约 1500 psi） 加挡圈 加挡圈

（上表为量级参考，实际取值须以密封件厂针对具体牌号和温度给出的压力-间隙曲线为准。）

油气井口的 70~103 MPa 远在这张表适用范围之外。在这个量级，90 Shore A 与挡圈不是可选项而是必要条件；压力双向交替时两侧都要放。挡圈材料上，PTFE 通用（-60~260℃），PEEK 强度与耐温更好，但对沟槽表面质量更敏感、成本也更高。

六、按部位拆：五个位置的材质分岔

井口采油树与阀门（API 6A）：设备按压力、温度、材料三个等级标注，材料等级 AA/BB/CC 为一般工况，DD/EE/FF/HH 为酸性工况。本体符合酸性工况不代表里面的弹性体也符合，密封件要看单独的报告。其中 K 级（-60~82℃）最难满足——金属做到 -60℃ 不难，常规弹性体做不到，只能选低温牌号（低温型 HNBR、FVMQ）或改成 PTFE 弹簧蓄能结构。

井下工具（封隔器、完井工具）：HNBR 是主力；温度到 150℃ 以上或同时有高硫与胺类缓蚀剂时，换 FEPM 或 FFKM。

地面脱硫与处理装置：MDEA/DEA 胺液 + H2S + 40~80℃，是 FKM 失效频率最高的场景之一——胺液让 FKM 脱氟降解，而 H2S 分压往往已过酸性门槛，这个位置用 FEPM。

稠油热采与蒸汽注入：200℃ 以上蒸汽 + H2S + 胺类缓蚀剂。FKM 在蒸汽中脱氟，EPDM 耐蒸汽但不耐烃，HNBR 温度上限不够，三个候选全部出局。

泵与往复压缩机：压力频繁循环、反复升压-泄压，属典型 RGD 工况，按 AED 牌号选并配挡圈限制位移。

七、落地：给现场的四步

  1. 先算分压，再谈材质。 总压 × H2S 体积分数；≥ 0.3 kPa 且存在液相水就按酸性工况选材，不要用"ppm 很低"做判断依据。
  2. 索要三样证据。 材质牌号（写到固化体系与硬度）、ISO 23936-2 或 NORSOK M-710 的 RGD 报告、实测硬度值（高压气工况一般 90 Shore A）。缺哪一样，都别按"供应商说可以"下单。
  3. 快泄压工况按 RGD 牌号选，并把泄压速率写进操作规程。 90 Shore A + 挡圈 + 延长放压时间，三件事一起做才有效。
  4. 换件不允许降级替换。 拿库存普通 FKM 顶 HNBR、拿 EPDM 顶蒸汽侧密封，是油气现场最常见的两类一次性错误。

按温度和介质筛材质、查尺寸，可先用站内工具页 /tool/（它的介质清单没有单列 H2S 与 CO2，酸性气工况仍需向供方索取具体牌号数据表）；分压计算、材质定级与替代方案，可以走 /contact/ 询单。

液压 O 型圈选型：压力、温度、介质打架时先服从谁

2026-10-04　·　技术文章

一个 20 MPa 的液压站，油温正常 55℃，夏季峰值 78℃。原设计用 NBR 70A，跑了一年多没问题。后来为了防火把 L-HM 矿物油换成了水-乙二醇（L-HFC），换油当天泵站不漏，一个月后缸体端盖、阀块接口开始渗油，拆开一看，O 型圈软塌塌的，指甲一按就掉渣。

密封件是同一批新货，尺寸、硬度、压缩率都没变——变的只有介质。

这类事故的共同点是：三个参数被拆开单独查表，查完各自都合格，合起来装上就出事。压力表查出来要 90A 硬圈，温度表查出来要软化材质，介质表查出来要另一门橡胶，三张表谁也不管谁。这篇讲三个参数互相拉扯时先服从谁、牺牲谁，以及怎么把它们折成一个能算的数。

一、三个参数各自在管什么

先弄清每个参数管什么，才知道它们什么时候打架。

参数 它管什么 出错的典型后果
压力 硬度、间隙、挡圈 咬伤、切口、掉块
温度 材质档次、压缩率取值 硬化开裂、永久变形
介质 材质门类（一票否决） 溶胀、软化、几天内报废

三者性质不对等：介质是否决项，温度是边界项，压力是设计项。介质选错几周内失效；温度超界，寿命从两三年掉到几个月；压力超出抗挤出能力，可能一次冲击就咬坏。难点在于压力和温度的偏好方向相反——压力要硬，温度要软（见第四节）。

二、优先级：介质先否决，再看边界，最后做设计

按这个顺序判，不要跳步。

第一步：介质做否决性筛查。 介质在禁用清单里，该材质直接出局，不讨论温度压力。矿物油、水基液、磷酸酯、可降解酯这几类，密封材料几乎互斥（见下节的表）。

第二步：温度卡边界。 用实际油温峰值比材质连续工作上限，不要用平均温度，也不要指望峰值余量。密封件周边温度比油箱油温通常高 10~20℃。

第三步：压力定硬度与结构。 定完材质再定硬度：低压靠软圈贴合，高压靠硬圈抗挤，超过临界值就加挡圈，而不是一味换更硬的料。

第四步：回头验算。 把前三步结论代进压缩率、槽满率、拉伸率三个算式，看是否自相矛盾。这步最容易被跳过，也最容易出事故。

一条例外：设备改不了时（沟槽已定型、油品由工艺决定），次序要反过来——先接受介质和温度的强制约束，再在剩余自由度里调硬度、调截面、加挡圈。 现实中的选型多半是被约束的一方。

三、真正的分岔口是液压油类型

大部分乱子根子不在压力也不在温度，而在没人问一句：这台设备用哪一种液压油？

液压油类别 代表牌号 温度区间 推荐密封材质 明确不能用
矿物油型 L-HL / L-HM / L-HV -20 ~ 80℃ NBR（80℃ 内）；FKM（80~120℃） EPDM 一接触就废
水-乙二醇 L-HFC -20 ~ 60℃ EPDM；可用 FKM NBR 会水解软化
磷酸酯 L-HFD-R 20 ~ 150℃ FKM（F 型 / GF 型）、PTFE NBR 剧烈溶胀
可降解酯 / 植物油 L-HEES / L-HETG -30 ~ 80℃ 专用牌号 PU、FKM 普通 NBR 会溶胀
高水基 L-HFAE / L-HFAS 5 ~ 60℃ 按供方确认，多数需特殊配方 通用材质基本都不适用

几条与站内选型工具一致的红线：

  • 水-乙二醇不能配 NBR。 水分渗入丁腈，把增塑剂和防老剂洗出来，乙二醇还会导致水解、破坏交联结构。表现是「软塌塌、一捏就碎」，不是常见的溶胀。
  • 磷酸酯不能配 NBR，也不能配 PU。 丁腈在磷酸酯里体积膨胀可达 50% 以上，几天就能挤满沟槽。磷酸酯路线选 FKM（A 型长期性能一般，建议 F 型或 GF 型）或 PTFE。
  • EPDM 绝不能进矿物油系统。 乙丙橡胶是非极性橡胶，遇矿物油迅速溶胀——这是最常见的「升级变降级」错误。
  • 硅橡胶（VMQ）与氟硅（FVMQ）都不耐矿物油，高温液压场合切忌选硅橡胶。FKM 虽耐油，但不耐热水蒸汽、酮酯、强碱与氨。

换油就要重算密封，这是硬约束。 最典型的事故序列是：设备改造把矿物油换成抗燃液，油品规格书写得很清楚，却没有一栏叫「密封件同步更换」。

有一条容易忽略：车间可能混用油品时，FKM 常比 EPDM 稳妥——FKM 对矿物油和水-乙二醇都能用，EPDM 只在水基液里完美、对矿物油零容忍。

四、温度与压力的折中：两个方向相反的偏好

温度要软。 温度升高，橡胶模量下降、弹性衰减加快。压缩率取在区间上限时，高温会加速应力松弛和压缩永久变形，圈很快「压死」不再回弹。所以高温工况通行做法是把压缩率往区间下限取。

压力要硬。 压力越高，橡胶越容易被推进配合间隙。提高硬度是最直接的手段，其次是减小间隙、加挡圈。

冲突就在这儿：既高温又高压时，你希望圈同时更软和更硬。取舍原则是：硬件能改（间隙、挡圈、沟槽）先改硬件；改不了才在材质和硬度上让步。

冲突情形 优先动作 次选动作 不建议
高压 + 常温 90A 硬化 + 间隙收紧 加 PTFE 挡圈 只加硬度不改间隙
高压 + 高温 加挡圈 + 90A + 提高温度等级材质 缩短更换周期 降硬度求贴合
常温 + 介质苛刻 先换材质门类 材质不变加 PTFE 包覆 靠加硬度硬扛
高温 + 介质苛刻 FKM / FFKM / PTFE 包覆 加冷却器降油温 用 NBR 加硬扛
低压 + 低温 60~70A 软圈、适当提高压缩率 改用低温牌号 上 90A（低温下更脆）

油温本身就是选型参数。 行业通行口径是油温超过 65℃ 后每再升高 10℃ 老化速率约翻倍，橡胶热老化同规律。同一只圈，60℃ 用两年、80℃ 可能只撑半年——把油温从 78℃ 压到 55℃，比换更贵的材质划算。

五、把三个参数折成一个数：三步算法

落到图纸上要有个能算的东西：

第一步，算出密封件周边实际温度。

T_密封 = 油温实测值 + 位置修正

位置修正经验值：油箱内 ≈ 0℃；主油路 ≈ +5℃；油缸端盖 ≈ +10~15℃；溢流阀、节流阀、泵壳体附近 ≈ +15~25℃。按峰值取值，不按平均值。

第二步，查介质兼容矩阵，做一票否决。

用「材料 × 介质」查一次，只留通过项。这步不看温度压力，纯粹筛掉不合法组合，站内的 选型工具 可直接跑。

第三步，在剩余材质里按温度定档次、按压力定硬度。

密封件周边温度 矿物油系统可选材质 提醒
≤ 80℃ NBR 70A；PU（耐磨件） NBR 上限 100℃，80℃ 已在寿命陡降区
80 ~ 100℃ NBR 90A、HNBR NBR 到 100℃ 必须核算寿命
100 ~ 150℃ HNBR、FKM FKM 低温只到 -20℃，寒区启动要核对
150 ~ 200℃ FKM 高温牌号 核对压缩永久变形数据
> 200℃ FFKM 价格与 FKM 差一个数量级，先确认有无必要

三步之后回头验算三个几何指标：

  • 压缩率 =（截面 − 沟槽深度）÷ 截面 × 100%
  • 槽满率 = O 型圈截面积 ÷ 沟槽截面积 × 100%，其中圈截面积 = π × (截面 ÷ 2)²，沟槽截面积 = 槽深 × 槽宽
  • 拉伸率 =（沟槽内径 − 圈内径）÷ 圈内径 × 100%

槽满率尤其要重视：常见建议上限 85%，介质溶胀或高温膨胀明显的工况压到 75% 甚至更低。上限的存在是因为橡胶线膨胀系数是钢的 7~20 倍——温度一上来涨得比金属沟槽快，圈必须有地方退让。

六、改工况与排故：必查项与失灵特征

设备改造、换油、提压提速最容易破坏原有平衡，逐项过这四项：

检查项 核对内容 不做会怎样
材质门类 新介质是否在禁用清单内 几周内溶胀软化、批量报废
温度边界 新工况峰值温度 vs 材质连续上限 寿命断崖式缩短，像「正常磨损」
槽满率 代入新介质溶胀率后是否仍 ≤85% 高温或溶胀后鼓圈、被挤进间隙
拉伸率 尺寸变更后是否仍 ≤5% 截面变细、压缩率虚降、早期疲劳

四项里最易漏的是槽满率。原因很实际：压缩率只要两个尺寸随口就能算，槽满率要量槽宽、算面积。但介质一换、溶胀率一变，第一个失效的往往是槽满率而非压缩率。

已经漏了的设备，可以按失效痕迹反推是哪个参数没守住，不必先从材质怀疑起：

  • 圈软塌、掉渣、一捏就碎 → 介质不兼容（NBR 遇水基液最典型）。查油品牌号，换 EPDM 或 FKM。
  • 截面变扁片、不回弹 → 温度超界叠加压缩永久变形。降油温或提温度等级。
  • 低压侧有飞边、缺口 → 压力挤出，间隙过大或硬度不够。加挡圈并收紧间隙。
  • 圈挤满沟槽、装配困难 → 槽满率超标，来自溶胀或槽宽偏窄。加宽沟槽或改用低溶胀材质。
  • 表面细密裂纹、硬化 → 热老化或臭氧老化。查温度，户外场合换 HNBR / EPDM。
  • 装后短时间即漏 → 安装损伤（切边、扭曲），与选型无关，查装配工序。

提醒一句：这几种痕迹经常同时出现，高温挤压的圈可能既有硬化裂纹又有低压侧缺口。这时优先修不可逆的那个——介质不兼容与热老化不可逆，间隙和挡圈可改。

七、给你的结论

液压 O 型圈选型记住四句话：介质一票否决，温度卡边界，压力定硬度和结构，几何三项收口验算。取舍次序：

  1. 介质选错没有补救空间，先确认油品牌号再谈其他，换油必须同步换密封。
  2. 温度和压力偏好方向相反，硬件（间隙、挡圈、冷却）能改就先改，别在材质上强行妥协。
  3. 油温是选型参数不是运行参数。65℃ 以上寿命陡降，把油温从 78℃ 压到 55℃，密封寿命可能翻几倍，比换更贵的材质划算。
  4. 压缩率、槽满率、拉伸率三项一起算，任何一项单看合格都不代表装上去能用。

手上有具体的温度、介质、压力组合，直接用 选型工具 跑一遍：输入工况温度与介质，先筛出合法材质门类，再按密封形式给出压缩率与硬度推荐。若卡在「既高温又高压、槽位又改不动」这类两难上，把沟槽尺寸、油品牌号、实测油温发到 询单页，按实际几何替你算一遍槽满率与压缩率的可用窗口。

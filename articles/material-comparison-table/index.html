O 型圈十种材质横向对比：耐温、介质、硬度、颜色、成本

2026-09-21　·　技术文章

仓库里堆着一堆黑色的 O 型圈，看着都一样。维修工凭经验挑了一个装到液压阀上，三天后渗油；换成另一个"看着差不多"的，一周后胀成了粗香肠。事后查材质：第一个是 EPDM，第二个是 VMQ——两个都不能碰矿物油。十个材质装在同一个盒子里，肉眼几乎分不出来，而选错一次的代价是一次停机。

这篇文章把所有常用材质的对照关系摊在一张表上，并讲清"怎么核实"——因为颜色和手感都会骗人。

一、十种材质横向对比总表

下表是本站工具页 /tool/ 的推荐依据，也是采购下单前该核对的基准。温度区间为长期可靠工作区间，峰值温度只在短时停机或启动阶段有效，不能按峰值规划寿命。

读这张表要先看两个地方，再看别的：

  • 最低温那一列。 NBR 的 -30℃ 和 FVMQ 的 -60℃ 差 30℃，在北方户外设备上就是"能用"和"一入冬就漏"的区别。而且低温失效是发硬失去弹性，不是老化，短期看不出来，冬天才爆发。
  • PTFE 那一行的硬度栏。 它没有 Shore A 值，因为它是塑料。纯 PTFE 圈靠内芯（通常是 FKM 或 VMQ）提供回弹力，把它当成橡胶圈来设计沟槽和压缩率会直接失败。

二、耐介质能力：决定成败的那一刀

温度不够只会缩短寿命，介质不兼容会当场失效。所以选材质的第一步是看介质，不是看温度。下表把十种材质按主要介质族归位。

这张表里有四条最容易踩的线，值得单独记住：

  1. EPDM 和 VMQ 都不耐矿物油。 这是现场最高频的选型事故。两者耐候耐臭氧都很强，外观又常是黑色或彩色，很容易被当成"通用材质"拿来替换 NBR。
  2. FKM 不耐酮、酯和热蒸汽。 很多人把氟橡胶当"万金油"——它耐油耐温确实一流，但遇到甲乙酮、酯型液压油、高温水蒸汽会脱氟降解，照样废。
  3. PU 不能长期泡水。 酯型聚氨酯的酯键会水解，70℃ 热水里几百小时强度就明显下滑；要用水环境就选醚型牌号，且只做短期接触。
  4. CR 耐矿物油只是中等。 它的强项是耐候、耐臭氧、耐制冷剂和阻燃自熄，不能拿它当 NBR 的平替去封液压油。

三、硬度：70A 是默认，90A 是高压

邵氏 A 硬度衡量的是橡胶抵抗压入的能力。硬度越高，接触应力越大、抗挤出能力越强，但需要更大的压缩力才能贴合，对密封面粗糙度也更敏感。

场景 推荐硬度 说明
真空 / 低压气动 60~70 Shore A 低压差下更容易变形贴合
静态密封（径向 / 端面） 70 Shore A 压缩量大、贴合好，可靠性最高
一般往复动密封（<0.5 m/s） 80 Shore A 兼顾弹性与耐磨
高压液压动密封（>16 MPa） 90 Shore A 抗挤出，或降硬度 + 加挡圈

三个实操要点：

  • 别只看硬度数字，要看材质能不能做到这个硬度。 硅橡胶常规只到 80 Shore A，PU 通常在 80~95，想让 VMQ 做 90A 需特殊牌号。
  • 硬度有公差。 常规标注方式为标称值 ±5 Shore，所以"70A"和"75A"在实物上可能测出来是一样的。拿单点硬度去判退一批货，是站不住脚的。
  • 高压工况优先加挡圈，而不是一味加硬度。 90A 圈的贴合性变差，有时反而不如"70A 圈 + 挡圈"的组合可靠。

硬度测量还有一个现场最容易忽略的坑：试样厚度。邵氏硬度计的压足和压针都需要足够厚度才能读准，标准试片通常要求 6mm 以上；直接拿一个 2mm 截面的 O 型圈去测，读数会明显偏高。薄截面件应改用微型硬度测试（M 型系统）或 IRHD 方法，且只在平面上对叠后测——这些都属于过程筛查手段，不能作为拒收批次的唯一依据。

四、颜色：能帮你缩小范围，但不能替你下结论

行业里有一套大家默契沿用的颜色习惯，它能防止装错，但不是强制标准。

颜色 最常见对应的材质 但要注意
黑色 NBR（最普遍） CR、HNBR、部分 FKM、FFKM 也常做成黑色，无法靠颜色区分
棕色 FKM（Viton） 历史来自早期氟碳聚合的氧化铁本色，航空航天文件里作为目视追溯标记
绿色 HNBR 或低温型 FKM 两者都常用绿色，必须查数据表
红色 VMQ 硅橡胶 部分 FKM、HNBR 也做红 / 酒红色
蓝色 FVMQ 氟硅橡胶 EPDM 也常有蓝色牌号，用途完全不同
白色 / 透明 VMQ、EPDM（食品级），PTFE 食品级 NBR 也做白色

有三点必须说透：

  • 颜色不是标准，是厂商约定。 目前没有哪个国际标准强制规定"某色 = 某材质"。唯一被规范约束的色标系统是饮用水密封的 EN 681-1 和燃气密封的 EN 549，其余都是各家自定。
  • 颜色也用来表达硬度和硫化体系，不只是材质。 同一种材质的不同硬度、过氧化物硫化与硫黄硫化，常靠颜色区分。所以两个绿色的圈，可能一个 70A 一个 90A。
  • 颜色最大的价值是现场防错，不是材质鉴定。 产线上用颜色区分"这台设备用哪个"，比看标签快得多；但反过来用颜色倒推材质，可靠性不够。

五、不确定材质时，三步核实

拆下来一个没有型号、没有标签的旧圈，颜色也说不清，按这个顺序做：

  1. 查供应商数据表或材质证明书（CoC）。 这是唯一可靠的方法。正规供应商能提供牌号、硬度、硫化体系、耐温区间和 FDA / WRAS 之类的认证信息。采购单上把这几个字段写清楚，比写"黑色 O 型圈"有用得多。
  2. 看外观和手感，缩小范围。 纯黑、偏硬、有油味，大概率是 NBR；纯黑、略软、无味，装在户外或蒸汽管路上，倾向 EPDM 或 CR；棕或绿、很硬、用在燃油系统，大概率是 FKM；半透明灰白或红色、柔软，用在食品或医疗场合，基本是 VMQ。这一步只能缩小范围，不能定论。
  3. 做溶胀试验验证。 拿一小块样品泡进实际介质里，在接近工况的温度下放 72 小时，测体积变化率。这套做法依据 GB/T 1690（等同 ISO 1817）。通用的判读线是体积变化率 ±10% 以内可接受，超过 20% 基本就要换材质；同时还要看硬度变化，泡完之后明显变软同样不合格。这一步最贵也最准，用于批量换型或关键工位。

六、成本梯度：钱花在哪一段

成本档由低到高：NBR / EPDM / CR → PU / VMQ → HNBR / FKM / PTFE → FVMQ → FFKM。相邻两档之间的差距不是线性的，从 FKM 跨到 FFKM 通常是十倍以上的量级。

场景判断 该选什么
常规油 / 气工况，-20~100℃ NBR，不要多花
油工况但温度 100~150℃ HNBR，比 FKM 便宜且够用
水 / 蒸汽 / 户外，不接触油 EPDM，便宜且最耐候
需要宽温域但不接触油 VMQ，性价比很高
燃油 + 极低温（-40℃ 以下） FVMQ，几乎唯一选择
高温耐油（150~200℃），介质常规 FKM，标准答案
强溶剂 / 强酸碱 / 酮酯 / 300℃ FFKM 或 PTFE 包覆圈
高压往复动密封，介质是矿物油 PU（避开热水与蒸汽）
制冷系统、耐候户外，成本敏感 CR，注意耐矿物油只是中等

成本控制的核心不是选便宜的材质，而是不要为用不上的性能付钱。 一个 80℃ 的常规液压阀，用 NBR 圈就够了；换成 FKM 不提升可靠性，只是把单价抬了几倍。反过来，在 180℃ 的热油里省 FKM 的钱去用 NBR，省下的每一分都会以停机的形式还回去。

七、三步定材质，收口在验证

把上面几节压成可以照着做的顺序：

  1. 定介质。 先确认是否接触矿物油系油品、酮酯、热蒸汽、强碱——这一步就能排除掉一半材质。
  2. 定温度。 用长期工作温度筛，不要用峰值温度。留出至少 20℃ 余量会更稳妥。
  3. 定运动方式与压力。 静态 70A、往复 80A、高压动密封 90A 或加挡圈，同时核算挤出间隙。

三步走完通常还剩两个以上候选，这时按成本从低到高收口，再用溶胀试验或小批量试用验证。

氯丁橡胶 CR O 型圈：耐候耐制冷剂老将，阻燃又栽在哪

2026-09-20　·　材质百科

一台冷库的蒸发器法兰漏了，拆下来的 O 型圈发硬、边缘一掰就断。维修工顺手换了个 NBR 圈，两个月后又漏；再换 EPDM，一个月不到胀成了一圈粗香肠。真正该用的，是那个被很多人以为"早就淘汰了"的老材质——氯丁橡胶 CR。

CR 是密封材料里的"均衡型选手"：单看任何一项都不算第一，但耐候、耐臭氧、耐制冷剂、阻燃、中等耐油这几样拼在一起，覆盖的场景至今没有便宜的替代品。 它的麻烦也一样明确：低温会结晶变硬，中高极性溶剂一律不碰。

一、CR 的分子结构：氯原子给了它什么

氯丁橡胶是氯丁二烯（2-氯-1,3-丁二烯）的聚合物，1931 年由杜邦以 Neoprene® 商品名率先商业化，是人类第一种量产合成橡胶。

它分子链上的氯原子决定了 CR 几乎所有性格：

结构特征 带来的性能 带来的代价
链上有极性氯原子 中等耐油、耐芳烃优于 NR/SBR 电绝缘性差，体积电阻仅 10¹⁰~10¹² Ω·cm
双键含量低（约 1.5%，远低于 NBR） 耐臭氧、耐候、耐热老化好 硫化体系特殊，需金属氧化物（ZnO/MgO）而非纯硫黄
链结构规整、极性大 机械强度高、抗撕裂、耐屈挠 易结晶，低温变硬
含氯量约 40% 天然阻燃、离火自熄 加工易粘辊，对温度敏感

常见两种牌号：G 型（硫黄调节）与 W 型（非硫调节）。W 型加工稳定性更好、储存期更长，是密封件厂主流。采购时只写"氯丁橡胶"，供应商可能两种都给，两者在焦烧倾向与压缩永久变形表现上并不相同，值得在规格书里点明。

二、耐温：两条边界，低温这边更难办

项目 数值 说明
长期工作温度 -40 ~ 120 ℃ 本站工具采用口径，通用牌号
短时峰值 130 ℃ 仅作短时应急
玻璃化转变温度 约 -40 ℃ 低于此值失去弹性
结晶温度区间 约 -35 ~ +32 ℃ 最麻烦的区间，正在工作温域内
分解温度 约 230 ℃ 远高于使用上限，超温先老化后分解

高温上限属常规老化，低温这边才是 CR 的独特麻烦。CR 分子链规整、极性强、内聚力大，分子热运动受限，因此特别容易结晶——本该在很低温度才发生的相变，被拉到了 -35~+32℃ 区间里。实际后果是：

  • 温度在 -10℃ 以上长期运行：回弹正常，性能稳定。
  • 温度掉到 -25℃ 左右：橡胶开始明显变硬，压缩永久变形（低温档）迅速上升。
  • 温度到 -40℃：到达玻璃化转变温度，完全脆化，一受冲击就断。
  • 温度回到常温后：已经结晶变硬的圈，需要几天时间才能恢复弹性。也就是说，一次寒潮留下的故障隐患，不会随气温回升自动消失。

判断：CR 适合"常年 0℃ 以上、偶尔冷启动"的工况。 如果是冷冻库、冷风机、北方户外设备这类要长期在 -20℃ 以下运行的场合，CR 不是好选择——该看硅橡胶 VMQ（-60℃ 起）或氟硅橡胶 FVMQ（-60℃ 起且耐油）。反过来，如果设备是常温工况、只在冬天停机时可能降到零下，CR 完全够用，不必为此升级材质。

三、耐介质：氯原子撑住了油和制冷剂，撑不住极性溶剂

CR 的耐介质清单很有个性：对非极性的油和气体友好，对中高极性溶剂全线失守。

介质类别 具体介质 CR 表现 说明
矿物油 液压油、机油、齿轮油 良 耐油性优于 NR/SBR，但不及 NBR，长期浸泡有中等溶胀
制冷剂 R12、R22、R502，氨、CO₂ 优 渗透率低，是冷冻行业传统主力材质
HFC 制冷剂 R134a 等 良 可用于汽车空调与制冷设备
水 / 常温 自来水、冷却水 良 耐水性良好
醇类 乙醇、甲醇 良 可在甲醇汽油、酒精类介质中使用
乙二醇 防冻液、冷却液 良 发动机冷却系统可用
臭氧 / 户外大气 紫外、臭氧、日光 优 耐候性仅次于 EPDM 与丁基橡胶
植物油 / 动物油 食用油、润滑脂 良 早期密封场合的常用材质
酮类 丙酮、丁酮 禁用 溶胀明显
酯类 乙酸乙酯、合成酯油 禁用 溶胀
芳香烃 苯、甲苯、二甲苯 禁用 显著溶胀，属 CR 的典型禁区
磷酸酯液压油 航空、电厂抗燃油 禁用 需改用 EPDM
醇醚型刹车油 DOT3 / DOT4 禁用 需改用 EPDM
热水 / 蒸汽 ≥100℃ 蒸汽、过热水 禁用 长期接触会老化开裂

三条容易踩的坑，这里单独说清：

  1. "耐油"不等于"耐所有油"。 CR 对矿物油的耐受只是"中等"，长期 100℃ 以上浸泡，溶胀与强度衰减都比 NBR 明显，不能当 NBR 的平替。
  2. 芳香烃是硬禁区。 有人以为 CR 极性大就"更耐溶剂"，恰恰相反：苯、甲苯、二甲苯会显著溶胀 CR，汽油柴油含芳香烃，只能短时接触。
  3. 刹车油必须绕开。 DOT3/DOT4 醇醚型是 EPDM 的专属领域，CR 同样不能用。

要确认某个具体介质与 CR 是否相容，用站内 材质选型工具 输入介质与温度，会输出推荐、需实测、排除三档结果和排除原因，比翻材质表可靠。

四、那它到今天还活在哪：四个过滤条件

CR 今天还能站住的场景，几乎都同时满足"户外或制冷剂 + 常温以上 + 需要阻燃或耐候"。四个条件就能把它框出来：

条件 CR 的答案
介质是制冷剂、氨、常温矿物油或户外大气？ 是
工作温度是否稳定在 -10℃ 以上、上限 100℃ 以内？ 是
是否需要阻燃、自熄或耐候长寿命？ 是
是否接触酮、酯、芳香烃、磷酸酯、刹车油或蒸汽？ 否

四条全为"是"，CR 通常就是成本最低的解；只要有一条为"否"，就该换材质。四类典型场景：

冷冻空调与制冷设备。 传统氟利昂（R12、R22、R502）以及氨、二氧化碳系统中的密封与垫片，CR 渗透率低、耐介质好，是长期主力。但冷冻机油若含高比例芳香烃就要重新评估——这正是很多"CR 用在制冷系统里莫名溶胀"的原因。

户外与海洋环境密封。 港口机械、船舶甲板设备、户外箱体长期受紫外、臭氧、盐雾侵蚀。CR 耐候性在通用橡胶中排第二梯队（仅次于 EPDM 与丁基橡胶），且比 EPDM 有更好的耐油与机械强度，是户外需要兼顾油介质时的折中选项。

阻燃与防爆要求场合。 CR 含氯约 40%，是通用橡胶中阻燃性最好的材质，离火自熄。矿用设备、防爆电气选它，是为了满足阻燃规范而非密封性能本身。

高机械强度的动态部位。 CR 拉伸强度、撕裂强度与耐屈挠性都好，常用于护套、防尘套、膜片、胶管外层这类反复弯曲或受剪切的结构件。

场景 常用材质 选 CR 的理由
冷冻空调（R22/氨） CR 耐制冷剂、低渗透率
户外设备外壳密封 CR / EPDM 耐候耐臭氧，CR 额外有耐油与阻燃优势
矿用、防爆电气 CR 阻燃自熄
汽车防尘套、膜片、胶管外层 CR 抗撕裂、耐屈挠
常温矿物油静密封 NBR CR 耐油不如 NBR 且更贵，没必要
100℃ 以上液压系统 NBR / HNBR / FKM CR 耐油与耐温都不够
-20℃ 以下低温工况 VMQ / FVMQ CR 低温结晶变硬
酮、酯、芳烃、刹车油、蒸汽 EPDM / FFKM / PTFE CR 全线禁用

五、和 NBR、EPDM 的分工：别把它当"便宜货"

CR 的价格档次与 NBR、EPDM 接近（低档），但它替代不了这两者中的任何一个，三者分工其实很清楚：

对比项 CR 氯丁 NBR 丁腈 EPDM 三元乙丙
耐温 -40 ~ 120℃ -30 ~ 100℃ -50 ~ 150℃
矿物油 / 液压油 良 优 禁用（溶胀）
汽油 / 柴油 短时可，长浸不推荐 优 禁用
制冷剂 / 氨 优 良 良
耐臭氧 / 户外 优 差 优（最好）
阻燃自熄 有 无 无
酮类 禁用 禁用 优
酯类 禁用 禁用 禁用
热水 / 蒸汽 禁用 禁用 优
磷酸酯液压油 禁用 禁用 优
醇醚型刹车油 禁用 禁用 优
低温弹性 一般（结晶倾向大） 一般 好
机械强度 / 抗撕裂 优 中 中
价格 低 低 低

要耐油选 NBR，要耐水耐候选 EPDM，要耐候兼耐油或要阻燃选 CR。 两个最常见的误用：CR 被当成 NBR 用在高温液压上（耐油不够），或当成 EPDM 用在蒸汽管路上（直接禁用）。

六、验收与储存：老材质的两个老问题

CR 出厂久了会自己变硬，这不是错觉。生胶在室温下会从线型 α 型逐渐转向支化、交联的 μ 型，也就是"自硫"（焦烧），G 型（硫黄调节）可存放约 10 个月，W 型（非硫调节）约 40 个月。对采购与使用方的实际含义有三条：

  • 看生产日期，不只看保质期。库存 CR 即便未开封，老化变硬也持续发生，高要求工位进料应做硬度复检。
  • 把压缩永久变形列为验收项。CR 属极性橡胶，分子间作用力强，物理压缩永久变形本来就偏大，这是它的固有短板。测试按 GB/T 7759.1-2015（等同 ISO 815-1）做，常规条件 100℃ × 70h、压缩率 25%，行业常用合格线是 ≤35%。关键工位应要求厂家提供实测值。
  • 储存按橡胶件通用规范。避光、避臭氧源（远离电机、电焊设备）、避油脂，25℃ 以下、湿度 65% 以下，平放不悬挂、不压重物，不与含硫或含溶剂材料混放。

结论：CR 的取舍

判断要不要用 CR，一条逻辑链就够：

  1. 先看介质：接触酮、酯、芳香烃、磷酸酯、醇醚型刹车油、热水蒸汽中的任何一个 → 直接排除 CR。
  2. 再看温度：长期低于 -10℃ 或高于 100℃ → 也不该用。
  3. 看有没有额外诉求：需要耐候长寿命、阻燃自熄、或高抗撕裂强度中的任意一条 → CR 的价值就出来了。
  4. 最后比价：常温矿物油场合 NBR 更耐油也更便宜，户外水系统 EPDM 更耐久也更便宜。CR 只在"耐候 + 耐油 + 阻燃"同时要的时候才划算。

CR 不是被淘汰的材质，而是一个适用范围很窄、替代成本很高的老将。真正出问题的从来不是 CR 本身，而是把它用在了不擅长的位置。

O 型圈标准对照：GB/T 3452.1、ISO 3601、JIS B 2401 与 AS568 能不能互换

2026-09-14　·　技术文章

"手上是进口设备的 O 型圈，能不能用国标件替换？"这是采购与维修中最常被问到的问题之一。答案是：截面接近，但不能直接互换，必须逐项核对。 下面讲清为什么。

一、四个标准的关系

标准 归属 截面系列（mm） 内径体系
GB/T 3452.1-2005 中国国标 1.8 / 2.65 / 3.55 / 5.3 / 7.0（G 系列） 优先数系（R10/R20）
ISO 3601-1 国际标准 与 GB G 系列基本一致 同 GB
JIS B 2401 日本工业标准 1.5 / 1.9 / 2.4 / 3.1 / 3.5 / 5.7 / 8.4 日标自有系列
AS568（SAE） 美国标准 1.78 / 2.62 / 3.53 / 5.33 / 6.99 英制内径 + 三位编码

关键结论：GB/T 3452.1-2005 等同采用 ISO 3601-1，所以国标件与符合 ISO 3601-1 的进口件在尺寸上可以对应；但 JIS 与 AS568 用的是它们自己的尺寸系列，不能直接当国标件用。

二、AS568 的截面看似接近，其实不等

AS568 的截面来自英制分数：

AS568 截面（英寸） 换算 mm 国标近似值 差值
1/16" 1.5875 1.8 0.21
3/32" 2.3813 2.65 0.27
1/8" 3.175 3.55 0.38
3/16" 4.7625 5.3 0.54
1/4" 6.35 7.0 0.65

看起来"差不多"，但换算回去的差距在 0.2~0.65 mm 之间。这对压缩率的影响是决定性的：

假设沟槽是按 1/8"（3.175 mm）截面设计的，你换上一个 3.55 mm 的国标圈，等于凭空多出 0.375 mm 的材料——压缩率会显著超出设计值，装不进、或者装进去后应力过大，短期就会损坏。反过来用 3.55 的沟槽配 3.175 的圈，则压缩不足、易泄漏。

所以：截面差超过 0.1 mm，就不要当"通用替代"处理，必须重新核算沟槽或找对应标准的件。

三、AS568 的编码规则

AS568 的规格用三位数编码，例如 -210、-014、-325。编码中隐含了截面系列和内径：

  • -001 ~ -099：小截面（1/16"）为主
  • -100 ~ -199：3/32" 截面系列
  • -200 ~ -299：1/8" 截面系列
  • -300 ~ -399：3/16" 截面系列
  • -400 ~ -499：1/4" 截面系列

例如 -210 属于 1/8"（3.175 mm）截面系列，内径 0.734 英寸 ≈ 18.64 mm。它和"国标内径 18"或"19"都不是同一个数，属于典型的"接近但不能混用"。

四、JIS B 2401 的系列与命名

JIS B 2401 按用途分几个系列，命名方式是一串字母加数字（如 P10、G25、V15）：

系列 用途 特点
P 系列 运动密封（活塞、活塞杆） 截面有 1.9 / 2.4 / 3.5 / 5.7 等
G 系列 固定密封（端面、法兰） 截面区间不同，压缩量更大
V 系列 真空密封 小截面为主

注意 JIS 的 G 系列和国标的 G 系列完全不是一回事，只是字母撞了。看到"G 系列"必须问清是哪个标准下的 G 系列，这是一个高频误解点。

五、替换判断的四个步骤

当你要用国标件替换进口件（或相反）时，按顺序做四件事：

第 1 步：确认内径能否对上。 把进口件内径换算成毫米，去国标里找最近值。找不到完全相等的（很常见），就进入第 2 步判断是否可接受。

第 2 步：确认截面偏差。 - 偏差 ≤ 0.1 mm：通常可接受，压缩率变化在安全窗口内 - 偏差 0.1~0.2 mm：需要核算压缩率，确认沟槽余量 - 偏差 > 0.2 mm：不要替换，直接找对应标准的件，或重新做沟槽

第 3 步：核对材质是否同级。 进口件上常标注材质代号（如 FKM 70、NBR 90）。只对尺寸、不管材质是最危险的替换方式——尺寸对上了，材质耐不了介质，同样会快速失效。

第 4 步：做实测验证。 取一件替换件装入原沟槽，测量装配后的实际压缩量，并在真实温度与介质下做 72 小时浸泡，观察体积变化率与硬度变化。批量替换前这一步不能省。

六、实用近似对照速查

仅用于初筛参考，不构成替换依据：

进口标称 换算 mm 国标最近规格 能否直接替换
AS568 1/16" 截面 1.5875 1.8 差值偏大，需核算沟槽
AS568 3/32" 截面 2.3813 2.65 差值偏大，需核算沟槽
AS568 1/8" 截面 3.175 3.55 差值大，不建议直接替换
AS568 3/16" 截面 4.7625 5.3 差值大，不建议直接替换
AS568 1/4" 截面 6.35 7.0 差值大，不建议直接替换
JIS P 系列 1.9 1.9 1.8 差值 0.1，可评估
JIS P 系列 2.4 2.4 2.65 差值偏大，需核算
JIS P 系列 3.5 3.5 3.55 差值 0.05，可评估

一句话总结：JIS 与国标更容易对上，AS568（英制）几乎都要重新核算。 遇到 AS568 的件，最省事的做法是保留原标准采购，而不是硬往国标上靠。

七、采购时的沟通要点

  • 报规格时同时写内径、截面和依据的标准，例如："内径 20，截面 2.65，GB/T 3452.1-2005"。只写 20×2.65 有时会被按非标理解。
  • 进口替代时，把原件的完整标注（含材质代号、标准号、批次）拍给供应商，让对方判断，而不是自己换算。
  • 要求供应商说明所供产品的实际标准来源。市场上存在"按 AS568 尺寸供货、标注国标号"的情况，会导致装配问题。

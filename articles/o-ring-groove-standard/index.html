O 型圈沟槽标准 GB/T 3452.3：尺寸表与公差怎么查

2026-10-01　·　技术文章

一台缸按国标图册做出来，试压就渗油。拆开量槽深：图纸标 1.35 mm，实测也是 1.35 mm，与 GB/T 3452.3 表里的数字一模一样。可没人算过 1.35 意味着什么——1.8 截面配这个槽深，压缩率 25.0%，而往复动密封的推荐区间是 12%~18%。

难的不是查表，是分清表里的量各是什么、哪些量不在表里。

一、GB/T 3452.3 管的是沟槽，不是密封圈

GB/T 3452.3-2005 只规定一件事：安装腔的尺寸与公差，适用对象是 GB/T 3452.1-2005 规定的那批 O 形圈。圈合格、沟槽合格，不等于系统能密封。

两条边界先记住：

  • 超过 10 MPa 要带挡圈。 这是标准写在范围里的结构型式要求，表 1、表 2 对应不带挡圈的沟槽。现场常说的「16 MPa 以上加挡圈」是经验口径，两者不冲突，但核对图纸应以 10 MPa 为下限；特殊应用的沟槽尺寸，标准原注写明由双方协商确定。
  • 它是修改采用（MOD），不是等同采用 ISO 3601-2:1999——对外文件写「按 ISO 3601-2」不等于「按 GB/T 3452.3」。

GB/T 3452 系列分五个部分，各管一段，不能互相替代：

部分 管什么 现场用途
3452.1 尺寸系列及公差 圈的内径、截面与规格代号
3452.2 外观质量检验规范 裂纹、缺料、毛边判定
3452.3 沟槽尺寸 槽宽、槽深、圆角、公差
3452.4 抗挤压环（挡环） 挡圈类型与尺寸
3452.5 弹性体材料规范 胶料性能指标

二、先认符号，再翻表

表里全是字母，认错一个就查错一行。标准第 3 章的符号：

符号 含义
d1 / d2 圈内径 / 截面直径
d3 活塞密封的沟槽槽底直径
d4 缸内径
d5 活塞杆直径
d6 活塞杆密封的沟槽槽底直径
d7 / d8 轴向密封的沟槽外径（受内压）/ 沟槽内径（受外压）
d9 / d10 活塞直径 / 活塞杆配合孔直径
b / b1 / b2 沟槽宽度：无挡圈 / 加一个 / 加两个挡圈
t / h 径向槽深 / 轴向槽深
z 导角长度
r1 / r2 槽底 / 槽棱圆角半径

最容易混的是 d3 与 t。 d3 是直径，t 才是槽深；把槽底径当成槽深抄进图纸，就会做出一个对不上的槽。

三、五种沟槽型式，两条核心算式

标准按压缩方向分两类五种型式：

型式 压缩方向 槽开在哪件上 基准尺寸
径向·活塞密封 垂直于轴线 活塞 缸内径 d4
径向·活塞杆密封 垂直于轴线 缸筒或导向套 活塞杆直径 d5
径向·带挡圈 垂直于轴线 同上，槽加宽 b1 / b2
轴向·受内压 平行于轴线 端面沟槽 沟槽外径 d7
轴向·受外压 平行于轴线 端面沟槽 沟槽内径 d8

四个算式决定成败：

活塞密封：d3max = d4min − 2t
活塞杆密封：d6min = d5max + 2t
轴向（受内压）：d7（基本尺寸）≤ d1 + 2d2
轴向（受外压）：d8（基本尺寸）≥ d1

前两式说明：径向密封的槽深不是可以独立标注的自由尺寸，它是 d3 与 d4（或 d6 与 d5）的公差叠加结果。 图纸只标 t、不标槽底径及其公差，加工方就无法保证压缩量。轴向密封相反，端面槽深是独立尺寸，所以公差表单独给了 h 的极限偏差，却没有 t——找不到 t 不是漏印，它由直径公差算出来。

标准第 6 章给了反推算路：由缸内径 d4（或活塞杆直径 d5）查表 8/表 9 定出圈规格，查表 3 取配合公差得 d4min（或 d5max），查表 1 取 t 算出 d3max 或 d6min。手上只有一个旧圈时，先用规格查询工具反查规格与公差，再回到这条链核对。

四、径向密封：槽宽、槽深、圆角、导角怎么查

表 1 的槽宽分三档，区别只在密封方式和挡圈数量：

1.80 2.2 2.4 3.8 5.2
2.65 3.4 3.6 5.0 6.4
3.55 4.6 4.8 6.2 7.6
5.30 6.9 7.1 9.0 10.9
7.00 9.3 9.5 12.3 15.1

槽深与圆角、导角在同一张表后半段：

截面 d2 t 液压动密封 t 气动动密封 t 静密封 最小导角 z 槽底圆角 r1 槽棱圆角 r2
1.80 1.35 1.40 1.32 1.1 0.2~0.4 0.1~0.3
2.65 2.10 2.15 2.00 1.5 0.2~0.4 0.1~0.3
3.55 2.85 2.95 2.90 1.8 0.4~0.8 0.1~0.3
5.30 4.35 4.50 4.31 2.7 0.4~0.8 0.1~0.3
7.00 5.85 6.10 5.85 3.6 0.8~1.2 0.1~0.3

读表要点：

槽宽是算出来的，不是拍出来的。 附录 A 写明：以体积溶胀 15% 为前提反算槽宽，沟槽最小体积取 O 形圈最大体积的 1.15 倍，再扣掉圆角占去的体积。所以 b 与截面的比值稳定在 1.33~1.36，落在行业常说的 1.1~1.5 倍里偏上。推论：材质溶胀超过 15%，这张槽宽表就不再够用，必须把 b 加宽。

挡圈厚度可以直接反推。 b1 − b 得 1.4 / 1.4 / 1.4 / 1.9 / 2.8 mm，b2 − b 正好是它的两倍。

气动的槽浅、压缩小。 1.8 截面：气动 1.40、液压 1.35——气动对摩擦热敏感。

静密封槽深最浅。 1.8 截面只有 1.32 mm，同档里压缩量最大。

表 1 的原注别漏：尺寸与公差适用于任何一种合成橡胶，但沟槽尺寸以硬度 70 IRHD 的丁腈橡胶为基准算出。 换成 90 Shore A 氟橡胶或低硬度硅胶，压缩率会变。

五、轴向密封：只有一档槽宽

端面密封的沟槽表简单得多：

截面 d2 沟槽宽度 b 沟槽深度 h 槽底圆角 r1 槽棱圆角 r2
1.80 2.6 1.28 0.2~0.4 0.1~0.3
2.65 3.8 1.97 0.2~0.4 0.1~0.3
3.55 5.0 2.75 0.4~0.8 0.1~0.3
5.30 7.3 4.24 0.4~0.8 0.1~0.3
7.00 9.7 5.72 0.8~1.2 0.1~0.3

没有 b1 / b2。 GB/T 3452.4 覆盖的挡圈场合是活塞、活塞杆动密封与径向静密封，不含轴向密封。

同一截面，轴向槽比径向槽浅。 1.8 截面：轴向 1.28，径向静密封 1.32。

沟槽相对 O 形圈有径向边界。 受内压时槽外径不得大于圈的外径（d1 + 2d2），受外压时槽内径不得小于圈的内径（d1）。1988 版此处用等号；这两条最常被漏，漏掉后表现为压力波动时端面渗漏。

六、槽深换算成压缩率：表 1 与附录 A 的落差

表 1 给的是槽深，不是压缩率，要自己算：

压缩率 =（截面 d2 − 槽深）/ 截面 d2

按标称截面把表 1 的三档槽深换算一遍：

截面 d2 液压动密封 t → 压缩率 气动动密封 t → 压缩率 静密封 t → 压缩率
1.80 1.35 → 25.0% 1.40 → 22.2% 1.32 → 26.7%
2.65 2.10 → 20.8% 2.15 → 18.9% 2.00 → 24.5%
3.55 2.85 → 19.7% 2.95 → 16.9% 2.90 → 18.3%
5.30 4.35 → 17.9% 4.50 → 15.1% 4.31 → 18.7%
7.00 5.85 → 16.4% 6.10 → 12.9% 5.85 → 16.4%

截面越小，压缩率越大。 1.8 截面静密封 26.7%，7.0 截面液压动密封只有 16.4%，同一张表差 10 个百分点以上。

标准自己的压缩率口径在资料性附录 A，写成「槽深极限值 → 对应压缩率」，区间含截面上下偏差，所以更宽：

截面 d2 径向·液压动密封 径向·气动动密封 径向·静密封 轴向密封 h → 压缩率
1.80 13.5%~28.5% 9.5%~25.5% 13.5%~30.5% 1.28 → 28.9%（22.5%~34.5%）
2.65 11.5%~24.0% 8.5%~22.0% 13.0%~28.0% 1.97 → 25.7%（21.0%~30.0%）
3.55 9.5%~23.0% 6.5%~20.0% 11.5%~27.5% 2.75 → 22.5%（19.0%~26.0%）
5.30 9.0%~20.5% 5.5%~17.0% 11.0%~26.0% 4.24 → 20.0%（16.0%~24.0%）
7.00 9.0%~19.5% 5.0%~15.5% 10.5%~24.0% 5.72 → 18.3%（15.0%~21.0%）

两张表叠起来看，得到一条逐档都能验证、却不写在明面上的结论：表 1 的槽深全部落在附录 A 深度区间的下限附近（1.8 截面液压动密封：表 1 给 1.35，区间 1.34~1.49；7.0 截面：表 1 给 5.85，区间 5.83~6.16）。照表 1 抄槽深，等于把压缩量用到该档允许范围的上限一侧；表尾原注也写着「允许沟槽深度值按实际需要选定」。

于是有了那个常见困惑：同一个「符合 GB/T 3452.3」，不同厂做出的槽深能差 0.1 mm 以上。标准给的是允许区间的偏端值，经验推荐区间是中值取向，用在不同环节：新设计按推荐区间定槽深（工具页推荐值是静态端面 20%~25%、静态径向 15%~20%、往复动态 12%~18%、旋转 8%~12%）；核算已有图纸则用附录 A 的允许区间，判断偏了还来不来得及。

落差最大的一处是：1.8 截面往复动密封，推荐 12%~18%，表 1 的槽深落在 25.0%，差 7 个百分点以上，摩擦热与压缩永久变形都会提前到来——与沟槽设计那篇一致。实操上照表 1 取值后把槽深往深里走 0.05~0.15 mm，让压缩率回落到推荐区间，前提是用附录 A 的极限值核对没走出区间。

七、公差与粗糙度：标准把误差往哪边推

表 3 最容易被跳过，它给的是公差配合代号，不再像 1988 版那样列数值：

尺寸 公差配合代号
缸内径 d4 H8
沟槽槽底直径（活塞密封）d3 h9
活塞直径 d9 / 活塞杆直径 d5 f7
沟槽槽底直径（活塞杆密封）d6 H9
活塞杆配合孔直径 d10 H8
轴向密封沟槽外径 d7 / 内径 d8 H11
沟槽宽度 b、b1、b2 极限偏差 +0.250
轴向密封沟槽深度 h 极限偏差 1.80 / 2.65 / 3.55 为 +0.050；5.30 / 7.00 为 +0.100

读一遍会发现：所有公差都是单向的，方向完全一致，全部朝着「沟槽容积变大、压缩量变小」。

  • 缸内径 d4 用 H8（只给正偏差）→ 孔径只会偏大 → 径向空间变大 → 压缩量变小；
  • 槽底径 d3 用 h9（只给负偏差）、d6 用 H9（只给正偏差）→ 偏离方向都是让压缩量变小；
  • 槽宽 b、b1、b2 只给 +0.250，槽深 h 只给 +0.05 / +0.10 → 槽只会偏宽、偏深。

标准在这里的取舍很明确：宁可牺牲一点压缩量，换取装配容错与溶胀余量，也不允许压缩量超上限。 所以「按名义值加工到正好」的结果，永远是压缩量比计算值小一点；有意义的下限核算是用最小截面配最深的槽算够不够。同轴度另列：d10 与 d6、d9 与 d3 之间，直径不大于 50 mm 时不得大于 φ0.025 mm，大于 50 mm 时不得大于 φ0.050 mm。

表 4 是表面粗糙度，最常被反过来用：

表面 应用情况 压力状况 Ra（μm） Rz（μm）
沟槽的底面和侧面 静密封 无交变、无脉冲 3.2（1.6） 12.5（6.3）
沟槽的底面和侧面 静密封 交变或脉冲 1.6 6.3
沟槽的底面和侧面 动密封 — 1.6（0.8） 6.3（3.2）
配合表面 静密封 无交变、无脉冲 1.6（0.8） 6.3（3.2）
配合表面 静密封 交变或脉冲 0.8 3.2
配合表面 动密封 — 0.4 1.6
导角表面 — — 3.2 12.5

括号内数值为要求精度较高的场合。配合表面比沟槽表面严一个量级——动密封配合面 Ra 0.4，沟槽面 Ra 1.6，而现场常见做法恰好相反：沟槽磨得很光，缸筒或活塞杆留着车削刀纹。有压力波动就提一档：静密封无脉冲时沟槽面 Ra 3.2、配合面 1.6，交变或脉冲则提到 1.6 和 0.8。

要按缸径或杆径反推圈规格，或核对图纸的槽深是否还在允许区间：用规格查询工具先查标准规格与公差，再按第三节算一遍。挡圈结构、材质与粗糙度要成套确认，把工况与图纸尺寸发到询单页。

O 型圈压缩永久变形：头号失效原因与验收判据

2026-10-14　·　技术文章

常见的一幕：设备静置不漏，一打压就渗。拆下 O 型圈，表面没有裂纹、没有变色、量内径外径都在公差内，于是判定"圈没问题，是沟槽的锅"。可把圈立起来看截面——它已经不是圆的，而是扁的、接近矩形，放一晚上也弹不回来。这就是压缩永久变形。它不裂、不烂、不变色，是密封圈最典型的"安静失效"，也是静密封故障里排第一的原因。

一、先分清两个词：压缩率是设计值，压缩永久变形是结果

这两个词常被混用，混了就没法谈。

压缩率是你在图纸上定的量：沟槽把圈压扁多少，W =（d2 − 沟槽深度）/ d2。静密封通常取 20%~25%。它回答"我让它压多少"。

压缩永久变形（Compression Set，简称 CS）是材料的回应：在温度、时间、介质共同作用下，卸去外力后还有多少变形回不来。它回答"它自己还剩多少弹力"。

两者只用一条式子就能挂上钩：

剩余有效压缩率 ≈ 设计压缩率 ×（1 − CS）

举例：设计压缩率 20%，材料在工况下的 CS 是 25%，长期运行后真正起作用的压缩量只有 20% × 0.75 = 15%。若这个工位的压力等级本就要求 15% 以上，泄漏就发生在这里——不是装配装错了，是选牌号时没把 CS 算进去。压缩率的取值范围见沟槽压缩率设计要点，本篇只谈材料这一侧。

二、怎么测：先问清方法，再来比数字

测出来的数值依赖计算公式，而公式有两套分支：

GB/T 7759 / ISO 815 压缩永久变形 CS = (t0 − t1) / (t0 − ts) × 100%

t0 = 试样原始厚度
t1 = 恢复后的厚度
ts = 限位块厚度（也就是压缩状态下试样的厚度）

关键在分母：分母是"实际施加的压缩量"，不是原始厚度。分子分母搞混会得到一个看着合理、实际偏小的数，这是这项试验里最常见的算错方式。

方法上有三条路，选错了试样会被压坏：

方法 施加方式 压缩量 适用
ASTM D395 方法 A 恒定载荷 1.8 kN 随材料软硬浮动 低硬度、软质材料
ASTM D395 方法 B 恒定形变（限位块） 通常 25% 密封件最常用
ASTM D395 方法 C 恒定形变，按硬度分档 ≤80 IRHD 取 25%；81~89 取 15%；≥90 取 10% 高硬度材料，避免压坏

对应的国标是 GB/T 7759.1-2015（常温与高温，等同 ISO 815-1）和 GB/T 7759.2-2014（低温，等同 ISO 815-2）。另外要分清测的是标准试片还是成品圈：O 型圈另有 ASTM D1414 成品件试验方法，同一材料做成成品圈后测出的 CS 通常比标准试片更差，因为多了一道硫化和脱模。

恢复时间是硬性规定：卸载后要在 23±2℃ 下恢复 30 分钟再测，而且要放在导热差的表面上。放 20 分钟测偏高，放 1 小时测偏低——同一根圈能测出两个结论。

温度与时间按工况对号入座：

试验条件 常用组合 大致对应的工况
低温 −20℃×22h 寒区户外、冷库
常温基线 23℃×70h 常温静密封对比
通用工业 70℃×22h 一般工业、建筑密封
中高温 100℃×70h 液压、汽车发动机舱
较高温 125℃×70h 制冷、EPDM 类工况
高温持久 150℃×70h（或 168h） HNBR / FKM 工况
超高温 200℃×70h、250℃×70h FKM / FFKM 工况

三、同一条件下谁更耐压：材质参考区间

这张表的价值不在于哪个数字绝对准，而在于让你看清同一材料不同牌号能差一倍。数值是参考量级，各家配方差异大，采购时以供方实测报告为准。

材质（硫化体系） 参考条件 CS 参考区间 说明
NBR（硫磺硫化） 100℃×70h 30%~50% 高温下回弹保持差，是常温液压件最常见的短板
NBR（过氧化物硫化） 100℃×70h 15%~25% 同一材料只换硫化体系，改善幅度可达一半
HNBR 150℃×70h 15%~25% 耐温上到 150℃，CS 仍能维持在中档
EPDM（过氧化物） 125℃×70h 15%~25% 耐候耐蒸汽的代价是耐油为零
FKM（双酚硫化） 200℃×70h 15%~30% 必须在 200℃ 条件下比，不能拿 70℃ 数据说事
FKM（过氧化物） 200℃×70h 10%~20% 同材质不同硫化体系，差出一倍
VMQ 硅橡胶 175℃×70h 20%~40% 波动最大的一类，订货要指定牌号
FFKM 全氟醚 250℃×70h 10%~20% 高温回弹保持最好，代价是价格
PU 聚氨酯 80℃×70h 不适用长期高温 耐温上限约 80℃，长期高温工况直接出局
PTFE 包覆圈 — 无此概念 塑料无弹性回弹，靠冷流贴合，须配弹簧或挡圈

表里的温度是试验温度，不是材料耐温上限，切勿倒着读。几条不能碰的红线：硅橡胶与 EPDM 都不耐矿物油与烃类；NBR 不耐臭氧、也不耐酮类与酯类（含醇醚型刹车油）；FKM 不耐酮酯、热水蒸汽与氨类；PU 会水解且耐温只有约 80℃；PTFE 无弹性、单独使用只适合静密封。具体材质的耐温区间与介质匹配，与站内选型工具的判定口径一致。

四、数字脱离条件就是废话：采购条款要写四件事

最常见的踩坑：采购单写"压缩永久变形 ≤ 20%"，供方回一份"70℃×22h 实测 12%"的报告。看着超额达标，其实两个条件根本不可比——把同一批料放到 100℃×70h，数字很可能直接翻倍。

所以比 CS 之前，这四个条件必须齐全：

  1. 试验温度（70℃ 还是 100℃、125℃）
  2. 保持时间（22h、70h 还是 168h）
  3. 压缩量（25% 还是按硬度分档的 15%）
  4. 方法与来源（ASTM D395 方法 B、ISO 815-1，还是 ASTM D1414 成品件）

再加两条更贴近工况的：是否先做介质浸泡或热空气老化再测（"老化后 CS"比原始 CS 有用得多）；试样是标准试片还是成品圈。

判据用行业通行门槛，不必照搬：

应用场景 常用门槛（条件需同行标注）
一般工业静密封 ≤35%
液压中低压 ≤25%
高压液压、精密 O 型圈 ≤20%，严格场景 ≤15%
汽车发动机舱 ≤25%（125℃ 条件）
航空航天、安全攸关 ≤15%，个别要求 ≤10%

但别把"越低越好"当信条。CS 是靠加大交联密度压下来的，压得越狠，拉伸强度与断裂伸长率越容易跟着掉，低温回弹也会变差。CS 是个权衡项，不是唯一项；供方报出异常低的数字时，先要全套物性数据，再要老化后的数据。

五、拆下来的旧圈能读出什么

现场读 CS 比送检快，方法只有三步：剪一段或取整圈放平（不要马上量）→ 等 30 分钟再测截面高度 → 与同规格新品对比，差额 / 新品截面 就是该工位实际发生的 CS 量级。

读数对照（用于现场排序，不用于验收）：

截面状态 判断 处理方向
接近圆形、侧面平整 CS 低，回弹仍在 圈不是漏点，回头查沟槽与装配
略扁，放置后能回弹 CS 中等，还在服役期 记下更换周期，观察趋势
明显扁平，放一夜仍不回弹 CS 高，密封力已不足 换圈，并核对实际温度与牌号
扁平 + 一侧缺口或毛边 CS 叠加挤出 除换牌号外还需加挡圈、缩间隙
扁平 + 变硬变脆 热老化叠加 CS 实测工位温度，通常超了设计值

务必把 CS 与挤出分开：CS 是整圈均匀压扁、没有缺口，属于分子网络的不可逆重排；挤出是局部被剪切掉，属于压力与间隙问题。两者处理方向完全不同，判错的代价是换了材料还是漏（见失效模式图鉴）。

还有一个反向陷阱：介质浸泡后，CS 有可能"看起来变好"。增塑剂被油抽出后圈变硬、体积收缩，尺寸小了，但回弹数据未必难看。所以耐介质试验必须把体积变化率和压缩永久变形一起看——收缩与溶胀都算劣化，只是方向相反，只看一个会得出相反的结论。

六、用它推算寿命：加速老化外推的边界

CS 随时间不是线性增长：前期快、后期趋缓，这个形状正是它能外推寿命的原因。同一牌号、同一压缩量，取 24h / 96h / 168h / 336h / 672h 五个时间点测 CS，画曲线后按阿伦尼乌斯关系外推。温度换算有个粗略经验规律：温度每升高约 10℃，橡胶老化速率大致翻倍——这是量级估算工具，不是精确公式。

三条边界必须记住：

  1. 同机理才有效。 温度抬得太高，失效机理可能从热氧老化切换成别的途径，外推结果失真；
  2. 有介质时更不可靠。 溶胀、抽出、水解会引入第二套机理，单纯按温度外推会严重高估寿命；
  3. CS 合格不等于寿命到点。 真正的判据是剩余有效压缩量是否还高于工况所需，而不是 CS 有没有超过某个数。

所以外推得到的数字，正确用法是排序与比较——比较两个牌号谁更能熬、换牌号能延长多少，而不是直接当成"能跑几年"写进合同。

七、结论与处理顺序

遇到静密封渗漏、外观又完好的圈，按这个顺序走：

  1. 实测工位温度，不要用图纸标注值；
  2. 算 剩余有效压缩率 = 设计压缩率 ×（1 − CS），对照压力等级判断裕度够不够；
  3. CS 超标时，优先改硫化体系与牌号（过氧化物硫化、后硫化处理都能显著压低 CS），而不是简单地"升级材质名称"；
  4. 拆下来的旧圈等 30 分钟再量截面，把该读数定为巡检项；
  5. 新工位在打样阶段就做一轮带介质的 CS 试验，比装上去漏了再返工便宜得多。

按温度与介质筛材质、按规格查尺寸与公差，用站内O 型圈查询与选型工具；需要指定牌号、指定试验条件或定制压缩永久变形指标的密封件，到询单页把工况写清楚。

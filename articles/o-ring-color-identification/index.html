O 型圈颜色到底代表什么：色标逻辑与现场鉴别

2026-09-23　·　技术文章

一个装了几百个圈的备件盒，标签掉了。红的最多，其次是黑的和绿的。凭"红色是硅胶"这条江湖经验挑了六个装到蒸汽管路上，一周内全部发硬开裂——那批红圈其实是过氧化物硫化的 EPDM。颜色在密封件行业里确实承载信息，但它承载的从来不是"材质"这一项。

一、颜色是配方标签，不是材质代号

需要先建立一个概念：橡胶的颜色来自配方里的着色剂（色母），而不是基胶本身。

除少数本色材料外，绝大多数橡胶生胶是半透明或浅琥珀色的，看起来都差不多。是生产厂家在混炼时加入炭黑或有机颜料，才把它做成黑色、红色、绿色。这意味着两件事：

  • 同一种材质可以做成任何颜色，只要换一包色母。NBR 能做黑色，也能做白色、蓝色、红色。
  • 同一种颜色可能来自完全不同的材质。颜色与材质之间没有化学绑定关系。

行业里那些"某某色代表某某材质"的说法，本质上是各家厂商多年形成的约定或内部标准，作用是产线防错和库存区分。它有点像仓库的货架编号——有用，但只是你自己家的编号。

唯一的例外是需要符合标准规定的场合。饮用水接触密封（EN 681-1 体系）、燃气密封（EN 549）等特定应用有明确的色标条款，颜色与标识由标准规定。除此之外，没有任何国际或国家标准强制规定"某色等于某材质"。

二、色标在传递哪些信息

既然颜色不绑定材质，厂商为什么还在用它？因为它同时在承担四类任务，材质只是其中最模糊的一类。

颜色在表达什么 具体含义 现场怎么用
材质类别 用不同颜色区分 NBR、FKM、VMQ 等，避免混料 只作同一供应商内部的区分，跨厂无效
硬度档位 同材质的 70A 与 90A 常靠颜色分开 需要先确认该厂的颜色—硬度对应表
硫化体系 硫黄硫化与过氧化物硫化常配色区分 关系到耐热与压缩永久变形，同样要查表
认证与用途 白色、本色多用于食品、医疗、饮用水接触件 颜色只是辅助，真正的依据是认证文件

第二、三条最容易被忽略。不少人以为颜色区分的是材质，实际不少厂用它区分同一材质的硬度与硫化体系。两个外观完全相同的绿色圈，可能一个是 70A 一个是 90A——装错不会立刻漏，但压缩率不对，寿命打折。

三、颜色与材质的常见对应关系

下面这张表汇总了行业里使用频率较高的颜色习惯。请把它当线索用，不要当结论用。

常见颜色 最常对应的材质 同色出现的其他材质
黑色 NBR（用量最大） CR、HNBR、部分 FKM、FFKM、PU、EPDM
棕色 / 墨绿 FKM（氟橡胶） 部分低温型 FKM 做成绿色
绿色 HNBR 低温型 FKM 也用绿色，两者必须查表区分
红色 VMQ 硅橡胶 部分 FKM、HNBR 也做红色或酒红色
蓝色 FVMQ 氟硅橡胶 EPDM 也有蓝色牌号，用途完全不同
白色 / 透明 VMQ、EPDM（食品医疗级） 食品级 NBR、FFKM 半导体件也做白色
琥珀色 / 半透明 PU 聚氨酯 部分聚酯型 PU 偏黄棕色
黄色 / 米色 多为过氧化物体系或食品级牌号 各厂差异最大，不建议作为判据

这张表说明一个现实：除"黑色大概率是 NBR"略可靠，其他颜色都至少对应两种主流材质。蓝色尤其典型——蓝色 FVMQ 耐燃油，蓝色 EPDM 绝对禁油，用反了就是事故。

四、没有一个"通用色卡"

很多人希望存在一张全行业通行的色卡。这个需求可以理解，但结论必须说清楚：它不存在。

色卡要成立，前提是生产端统一执行。而密封件是高度分层的行业：原料厂供混炼胶，制品厂按自己的配方和客户要求配色，同一款材质不同批次都可能因色母批次差异出现色差。要全行业统一，需要一个强制标准去约束，目前没有。

行业里流传的色卡大致三类来源：厂商的内部编码表被同行传抄后当成通用规则；某些设备原厂的备件标识约定，只对应原厂件；供应商为方便报价做的简化分类，颗粒度很粗。

这些表都有价值，共同点是只在自己的语境里有效。把它当通用标准，等于把某家厂的内部编号当成了国标。

五、没有标签时，用三个试验缩小范围

先明确一条底线：非破坏性方法只能缩小范围，不能定论。唯一能定性的是材质证明书、批次报告或实验室红外光谱分析。下面三步是现场在没有这些文件时的常用手段，需要剪样、属于破坏性试验，价值在于排除错误选项。

5.1 密度试验（最快，先做）

不同橡胶的密度差异明显，用一杯水加盐就能粗测。原理是含氟材质比重大、硅橡胶比重小。

材质 大致密度（g/cm³） 在水中的表现
VMQ 硅橡胶 1.1 ~ 1.25 几乎浮着或缓慢下沉
EPDM 1.1 ~ 1.3 缓慢下沉
NBR / CR / HNBR 1.2 ~ 1.5 下沉
PU 1.15 ~ 1.25 缓慢下沉
FKM / FVMQ 1.8 ~ 2.0 迅速下沉，明显沉底
FFKM 1.9 ~ 2.1 迅速沉底
PTFE 2.1 ~ 2.2 最沉

这一步的价值在于一刀切开含氟与不含氟。沉得又快又干脆的，大概率是 FKM、FVMQ 或 FFKM；浮在水面的基本排除含氟材质。要注意： - 密度受填料影响极大，同材质不同配方可差 0.2 以上，重填料的硅胶也可能沉水； - 只做粗筛，不能当验收依据。

5.2 燃烧试验（信息量最大，但最难判）

用镊子夹住一小块，在远离易燃物的通风处用打火机点燃，观察火焰、烟雾与气味，然后吹熄看残渣。

材质 燃烧特征 气味 离火后
NBR 黑烟多，火焰带黄 烧焦的橡胶味、略刺鼻 继续燃烧
HNBR 与 NBR 接近 焦橡胶味 继续燃烧
EPDM 烟较淡 类似烧蜡烛、略甜 继续燃烧
VMQ 硅橡胶 白烟，明亮火焰 几乎没有刺激味 残渣为白色粉末状二氧化硅
FVMQ 白烟带氟特征 刺激性略强 残渣白粉
FKM / FFKM 难燃、离火自熄 明显刺激性、类似盐酸味 残渣发黑结炭
CR 氯丁 难燃、有绿色焰边 刺激性，类似盐酸味 自熄
PU 黑烟浓 刺鼻的酸味 继续燃烧

判读要点： - FKM、FFKM、CR 含卤素，共同特征是难燃、自熄、气味刺激，能把它们和 NBR、EPDM、VMQ 分开。 - VMQ、FVMQ 燃烧后残渣是白色粉末，这是最干净的判据之一。 - FKM 与 CR 气味接近，仍要靠燃烧难易和焰边颜色区分，可靠性一般。 - 含卤素材料燃烧生成酸性气体，必须通风，绝不能凑近闻；试验后样品直接废弃。

5.3 溶剂浸泡试验（最接近实际工况，最该做）

前两步都在猜材质，这一步直接回答真正的问题：它在这个介质里行吗。

做法是取样称重，泡进实际使用的介质里，在接近工况的温度下放置 72 小时（按 GB/T 1690 / ISO 1817），取出擦干后测体积变化率和硬度变化。

体积变化率 判读 处置
-5% ~ +10% 兼容 可继续使用，记录备案
+10% ~ +20% 需评估 短期可用，长寿命工况更换材质
> +20% 不兼容 必须换材质，加大沟槽也救不回来
明显收缩（< -5%） 析出或降解 换材质，收缩会导致预压缩量下降而泄漏

这一步最花时间，但结论真正能落地。两个附加判据：浸泡后硬度下降超过 10 度，同样判不兼容；表面发粘、变脆或出现裂纹，直接判不合格，不必等体积数据。

六、气味和外观能提供多少信息

在动手做试验之前，闻一下、看一眼，能先建立起大致方向。下表是经验性对应，可靠性低于上面三个试验，只用来决定"先试哪一步"。

观察项 倾向判断
无味或极淡的蜡味，表面干爽 VMQ、EPDM 可能性大
轻微的橡胶或油味 NBR、HNBR、CR
明显刺鼻、偏酸或焦味 FKM、FFKM，或已热老化的样品
半透明、发黄、表面偏滑 PU
表面发粘、有析出物 已老化或曾接触不兼容介质，别再用它做判据
纯白或本色、手感柔软 食品医疗级 VMQ 或 EPDM
白色但很硬、几乎无弹性 PTFE 或 PTFE 包覆件

气味法有一条硬限制：样品若在高温或油烟环境用过一段时间，老化会彻底改变气味特征，判断基本不可靠。新件闻味道有意义，拆下来的旧件意义不大。

七、把颜色用对：三个落地建议

颜色的真正价值在防错和追溯，把它用在这两处回报最高。

第一，让供应商在材质证明书上写全字段。采购单上不要只写"黑色 O 型圈"，而应写明材质代号、硬度与公差、硫化体系、耐温区间和要求的认证。同时要求随批提供材质证明书或批次报告。颜色只能写辅助描述，不能作为唯一规格。

第二，在自己厂里建立内部颜色编码。材质混用时自建一张内部色卡：同一台设备只用一个颜色，换颜色即表示换材质。它能做到让保全工几乎装不错，成本极低。关键是写成正式文件贴到备件柜上，而不是靠师傅口口相传。

第三，把旧件的颜色当作提问的起点，而不是答案。看到颜色后去查对应供应商的颜色表，再配上面三个试验交叉验证。颜色负责缩小范围，材质结论必须落在文件或试验上。

半导体设备 O 型圈：耐等离子体不是一种材质

2026-10-08　·　技术文章

别的行业里，密封件失效的标志是漏；在半导体厂，这套判断会失灵——圈还平整地压在密封面上，不渗不漏，压力也保得住，但 wafer 上的颗粒缺陷突然多了一批，整片报废。 密封件的真正失效，是它什么都没漏，却什么都放出来了。

这条差异会一路传导到选材。行业里最常见的采购话术「我们用的是耐等离子体的 FFKM」，恰恰把两件事混成了一件：耐等离子体不是材质，而是配方能力。

一、失效定义不同：这里怕的是污染，不是漏

半导体密封件的失效路径是：密封面释放痕量物质或脱落颗粒 → 污染 wafer 或薄膜 → 颗粒缺陷与电学异常 → 良率下降。整个过程里密封件可能一直密封良好，验收口径因此从「耐不耐得住」换成「放不放出来」。

对应的文件是 SEMI F51《Guide for Elastomeric Sealing Technology》（2000 年首发、2015 年更新，正在修订），管材料选择、性能评估、洁净度与包装处理，检测项如下：

检测项 测什么 做法
可萃取物 从超纯水、酸碱、溶剂中萃取出的阴离子与痕量金属 浸提后 ICP-MS / 离子色谱
灰分 材料本体的金属元素总量 灰化后 ICP-MS
颗粒脱落 半导体最致命的污染形式，却不在 SEMI F51 的要求清单里 需另用超纯水萃取 + 液体颗粒计数

最后一行最该记住：采购单写「符合 SEMI F51」，回答不了「掉不掉颗粒」。而「半导体级」也覆盖不了多大差距——第三方公开实测里，两家供应商的密封件可萃取硫酸盐一项就差 18 倍，TOC 的排序又正好反过来。没有单一指标能说明干净程度。

二、等离子体不是一个工况，是一族工况

等离子体对弹性体有两条独立攻击路径：自由基的化学侵蚀（生成挥发性产物被抽走）和离子的物理溅射（轰击打掉表面）。主导哪条取决于密封件在设备里的位置，这就决定了一件反常识的事：同一台刻蚀机里，不同位置的圈不该是同一个牌号。

暴露位置 主导机理 材料档位
源附近、wafer 上方 离子物理溅射 必须用填充型；无填料蚀得太快，直接漏
远离源、wafer 下方、下游腔 自由基化学侵蚀，速率更低 可用无填料或轻填料
排气与尾管 颗粒随气流排走 洁净度要求最低，材质可大幅降档

正因主导机理随位置变，「耐等离子体」不构成完整规格，合格写法要带上反应器型式、气体配比、RF 功率、压力、温度与位置。更要紧的是，不同来源的蚀刻速率数据不能横向比——下面两组都是公开实测，单位都不同：

测试条件 PTFE FFKM FKM
含氟等离子体，蚀刻速率（μm/min） 0.04 0.27 ~ 0.38 0.73
等离子体自由基暴露，侵蚀速率（μm/1000h） 27.7 32.9 ~ 64.2 —

两组里唯一一致的是「普通 FKM 最差」，PTFE 与 FFKM 的排序正好相反，原因就在机理差异——照着蚀刻速率表选材是会选错的。 顺便澄清：PTFE 出局不是因为它蚀得快（自由基环境下它的数据甚至低于多数 FFKM），而是它不是弹性体、离子轰击下易微裂，碎屑变成颗粒源。

三、同样叫 FFKM，决定寿命的是填料

侵蚀分三步：聚合物先被蚀掉 → 无机填料裸露 → 填料颗粒脱落进腔体。 第三步才致命，所以有一类填料在近腔体位置是明确禁区：炭黑——颗粒落到 wafer 上会直接造成电路短路。传统高纯 FFKM 的无机填料常含第二族元素或过渡金属，蚀掉后留在表面；近十年半导体级 FFKM 的分水岭是聚合物填料，与基体同步蚀掉、不留残留。

填料类型 侵蚀后留下什么 建议位置
炭黑 导电炭黑颗粒，落到 wafer 上短路 不建议用于任何近腔体位置
硅酸盐、金属氧化物等无机填料 无机颗粒残留，含金属杂元素 远离等离子体源、下游与排气段
聚合物填料 与基体同步蚀掉，残留极低 可直接面对等离子体

结论很实际：同一品牌下，「通用型」与「等离子体专用型」的差别不在基体聚合物，在填料与配方——采购只写「FFKM」，等于把这层差异交给供应商决定。 寿命的计量单位也跟着变：厂商公开案例里，HDP-CVD 隔离阀的密封件改用聚合物填料牌号后，寿命从约 5,000 wafer 周期翻倍到三倍。这里要用 wafer 数或 RF 小时算，用「几个月」算没有意义。

四、湿法化学区：分岔在萃取物，不在耐腐蚀

湿法区的逻辑又换了一次。化学品确实凶，但真正的分岔点是往化学品里放出多少东西——低可萃取物、低离子污染、低痕量金属。

湿法工序 典型条件 材质判断
SPM（硫酸 + 双氧水） 约 120 ~ 160℃ 多数橡胶退场，走 FFKM 或全 PTFE / PFA 流路
SC-1（NH₄OH + H₂O₂ + H₂O） 约 65 ~ 75℃ FKM 出局（不耐氨与强碱），用 FFKM 或 PTFE
HF / BOE 与稀酸 常温 ~ 80℃ PTFE 最可靠；FKM 只能用于辅助位置
超纯水与臭氧水 常温 EPDM 可用，重点看萃取物指标

EPDM 在半导体里不是无关材料：耐水、耐臭氧、耐碱，在超纯水与一般湿法支路是成本友好的一档，但两条红线要先过——见矿物油即废，萃取物水平也高于半导体级 FFKM，只能放非关键位置。反过来说，几种常见材质在这里基本没位置：

材质 在半导体场景的问题
NBR 丁腈 不耐臭氧与紫外、不耐酸碱、不耐酮酯（光刻胶溶剂一类）
PU 聚氨酯 会水解，而超纯水与湿热正是它的死穴；耐温上限仅 80℃
VMQ 硅橡胶 强度低、耐强碱差、见矿物油即废；硅氧烷挥发物在真空紫外下有沉积风险

五、真空与热制程：真正的指标是压缩永久变形

真空、沉积、扩散这类制程里，工艺气体大多与材质相容，化学腐蚀往往不是主要矛盾，失效来自另一个方向：圈失去回弹。 典型症状是抽不到底压、冷却后漏、泵降时间变长——都不是被腐蚀，而是压缩永久变形超标：材料化学上耐得住，但压下去起不来，接触应力就没了。

第二个易忽略点：要测密封位置的温度，不是腔体温度——密封唇口与局部暴露截面的温度高于本体实测值，这是热老化的隐藏加速器。多数等离子体与 CVD 工位的密封点落在 200 ~ 250℃，部分高温工艺到 300℃。这一档里 FFKM 是唯一仍保持弹性的选择（本站工具口径 -20 ~ 300℃）；PTFE 耐温够但没有弹性，只能做静密封。

还有一条：静密封和动密封不能共用一套数据。 腔体盖、观察窗、法兰是静密封；狭缝阀、闸阀、隔离阀是动密封，还要看磨损与自身颗粒。拿静密封数据去选动密封，是这一行最常见的错误之一。

六、被忽略的另一半：SubFAB

SEMI F51 修订草案把密封位置分成八类，其中两类专门落在 SubFAB：苛刻工况（干泵、尾管、减排装置、腐蚀性尾气）与一般工况（支撑真空、泵公用工程、厂务接口）。标准单独给 SubFAB 留两类本身就是信号：这里和腔体内部逻辑不同。

区别在三处：介质是工艺副产物而非设计介质；位置「脏」，颗粒随尾气排走；换件节奏跟工艺维护走。所以 SubFAB 要的是「够用 + 换得起」，把 FFKM 铺到这里是纯浪费。 一条红线要说清：干式真空泵没有泵油，可以用 EPDM；旋片泵一类有油泵的泵油是矿物油，EPDM 在这里会溶胀失效。 尾气含 HF、Cl₂ 时 FKM 可胜任部分位置，但它怕氨与强碱，遇碱性清洗须另判。

七、采购清单：不能只写「FFKM」三个字

项目 要写清什么
厂商 + 牌号 具体牌号，不接受只写材质名；不同牌号的耐温、压变、耐等离子体性能可差一个量级
填料类型 聚合物填料还是无机填料，是否无金属、无卤素
洁净度与包装 洁净室清洗、双层袋装，半导体通常按 ISO Class 5 起
检测文件 可萃取物、灰分、放气、TOC 的实测报告，且针对你的工艺
变更控制 批次可追溯，配方变更必须通知；未通知的变更常是产线事故来源

SEMI F51 是「指南」，不是「合格证」——名称里的 Guide 就是这个意思。「符合 F51」回答不了「它掉不掉颗粒」。

判断顺序收成三步：先定失效定义——是「漏」还是「污染」，是污染就按可萃取物与颗粒找牌号；再定暴露位置；最后才比价格——位置定错，省下的钱一次良率损失就还回去了。

本站的 O 型圈选型工具 帮不上等离子体这一档：它按化学相容性排列介质，而等离子体是离子与自由基的混合攻击，不是化学品。但湿法与真空部分仍可借它的口径：HF 与硫酸借「稀酸」、SC-1 借「强碱」、超纯水借「水（常温）」但温度填工艺温度；真空与热制程借「空气」——十种材质在空气这一栏都是推荐，分岔在放气率与压缩永久变形。 要按位置和配方定牌号的，把工艺气体、暴露位置、温度与洁净度等级发到 询单页。

如果你问"哪种橡胶能同时扛住 -60℃ 低温和 200℃ 高温"，答案只有一个——硅橡胶。它是所有通用弹性体里温域最宽的一种，宽到其他材质没法用"接近"来形容。

但它身上同时挂着两个标签：**温域之王**和**耐油废柴**。多数硅橡胶密封事故，都是只看见第一个标签造成的。

## 一、硅氧主链决定了它的一切

其他橡胶——NBR、EPDM、FKM、PU——分子主链都是碳原子。硅橡胶不是：它的主链由**硅原子和氧原子交替**构成（Si—O—Si），这是它全部性能差异的源头。

- **Si—O 键能约 450 kJ/mol**，明显高于 C—C 键的约 347 kJ/mol。键越难被打断，耐热性就越好，这是硅橡胶能长期工作在 200℃ 的根本原因。
- **主链极其柔顺**，玻璃化转变温度低至 -120℃ 附近。所以它在 -60℃ 仍有弹性，而不是像 NBR 那样硬得失去密封能力。
- **极性低**。好处是电绝缘性极佳、生理惰性、无毒无味；坏处是**对同样非极性的矿物油、燃油几乎没有抵抗力**——油分子很容易钻进分子链之间，把橡胶泡胀。

一句话记住：**硅橡胶的耐热耐寒来自 Si—O 主链，它的不耐油也来自同一处。**这不是配方能修好的短板，加料只能缓解，改不了本性。

## 二、温度：它真正的主场

| 项目 | 数值 |
|---|---|
| 长期工作温度（标准配方） | -60℃ ~ +200℃ |
| 长期工作温度（高规格配方） | 可到 +230℃ |
| 短时耐受 | 约 +260℃ |
| 低温柔性下限 | -60℃ 仍保持弹性 |
| 常用硬度 | 50 / 70 Shore A（供货范围 40~80） |
| 拉伸强度 | 5~12 MPa（偏低） |
| 撕裂强度 | 低，这是它的机械短板 |
| 压缩永久变形 | ≤25%（175℃ × 22h 条件下） |

温度这一项，横向比一下就知道差距有多大：

| 材质 | 温域 | 耐油 |
|---|---|---|
| **硅橡胶 VMQ** | **-60 ~ 200℃** | 差 |
| EPDM | -50 ~ 150℃ | 差 |
| NBR | -30 ~ 100℃ | 好 |
| FKM | -20 ~ 200℃ | 优 |

FKM 的高温上限和硅橡胶接近，但低温只能到 -20℃ 上下。**如果你的工况要在 -40℃ 以下启动、或者跨度超过 150℃，硅橡胶几乎是唯一解。**

有一点要提醒：硅橡胶长时间贴着 200℃ 上限运行，会逐渐硬化、变脆、回弹变差——这是热老化，不是它"不行"，而是任何橡胶都有寿命账。预留 20~30℃ 余量，寿命会明显拉长。

## 三、它真正耐受的介质

| 介质 | 评价 | 说明 |
|---|---|---|
| 干热空气（至 200℃） | 推荐 | 硅橡胶最擅长的场景 |
| 臭氧、紫外线、大气老化 | 推荐 | 长期户外暴晒不裂 |
| 水（至 100℃） | 推荐 | 常温冷水、热水均可 |
| 醇类、乙二醇 | 有限 | 可用，浓度与温度高时需验证 |
| 稀酸、稀碱 | 有限 | 短期接触尚可，长期不建议 |
| 蒸汽（至 150℃） | 有限 | 短期可用，长期必须改 EPDM |
| 矿物油、液压油、机油 | **不推荐** | 溶胀 + 强度下降 |
| 汽油、柴油 | **不推荐** | 溶胀严重 |
| 芳香烃、酮类、酯类 | **不推荐** | 溶胀或降解 |
| 浓酸、浓碱 | **不推荐** | 化学侵蚀 |

## 四、它明确不耐的介质（按踩坑频率排序）

**1. 矿物油与燃油——最高频的事故**

液压油、机油、齿轮油、汽油、柴油，全是硅橡胶的禁区。很多人看到"耐 200℃"就把它塞进高温液压系统，结果几周内密封圈体积膨胀、硬度掉一半，然后漏油。**高温液压该选 FKM 或 HNBR，不是硅橡胶。**

**2. 高温蒸汽与热水（长期）**

硅橡胶短期接触 150℃ 蒸汽还能撑，长期会被水解降解，变软发粘。长期蒸汽工况的标准答案是 **EPDM**——耐温稍低（150℃），但耐蒸汽能力是另一个量级，而且便宜。

**3. 动态密封——它做不了**

硅橡胶拉伸强度和撕裂强度都低。往复、旋转、有摩擦的场合，它会快速磨损、撕裂、掉渣。**硅橡胶是静态密封材质，没有例外。** 需要动密封就换 NBR、HNBR 或聚氨酯（PU）。

**4. 高压气体与真空——气体会穿过去**

硅橡胶的气体渗透率显著高于其他通用橡胶。它不会被气体"腐蚀"，但气体会直接透过密封体渗漏，看起来就像密封失效。气密和真空场合要用丁基橡胶（IIR）或 FKM。

**5. 密闭高温、缺氧环境——会解聚**

这是一个冷门但真实存在的失效模式：在密闭、无氧的高温腔体里，硅橡胶的分子链会重新断裂解聚（reversion），橡胶变成黏糊状。热空气敞开环境没事，密闭高温腔体就有风险。

## 五、铂金硫化与过氧化物硫化，采购必须分清

同样是硅橡胶，硫化体系不同，价格和适用场合差得很远：

| 项目 | 铂金硫化 | 过氧化物硫化 |
|---|---|---|
| 纯度 | 极高，无有机酸副产物 | 一般，含微量副产物 |
| 气味 | 无味 | 轻微气味 |
| 透光度 | 好，不易发黄 | 可能发黄 |
| 拉伸强度 | 较高 | 常规 |
| 成本 | 高 | 低 |
| 适用 | 食品、医疗、高纯度场合 | 工业耐热、通用静态密封 |

**凡是接触食品、药品、饮用水的场合，必须指定铂金硫化**，并要求供应商提供 **FDA 21 CFR 177.2600** 符合性文件；医疗器械接触场合还要看 **USP Class VI** 报告。普通工业耐热用途，过氧化物硫化足够，没必要多花钱。

## 六、什么时候选它，什么时候别碰

| 场景 | 判断 |
|---|---|
| 温度低于 -40℃，或温域跨度极大 | ✅ 首选 |
| 食品、饮料、制药设备密封 | ✅ 首选（铂金硫化 + FDA 文件） |
| 电气、电子、灯具的密封与防护 | ✅ 首选（绝缘性好、耐候） |
| 户外长期暴晒、耐臭氧要求高 | ✅ 合适 |
| 高温液压油、机油、燃油 | ❌ 换 FKM / HNBR / NBR |
| 长期蒸汽、高温热水 | ❌ 换 EPDM |
| 往复或旋转动密封 | ❌ 换 NBR / HNBR / PU |
| 真空、高压气密 | ❌ 换 IIR / FKM |
| 大批量低成本通用密封 | ❌ 用 NBR 更划算 |

## 七、采购与验收要点

- **硬度**：常用 50 和 70 Shore A。偏软的（50 以下）密封贴合性好但抗挤出差，偏硬的（70 以上）抗压但需要更大压紧力。
- **颜色**：红色最常见，透明和白色多用于食品、医疗（便于观察污染）。颜色不影响性能，但**同一条产线上用不同颜色区分材质，是防止装错的有效手段**。
- **要文件**：食品级要 FDA 报告，医疗级要 USP Class VI，不要只看供应商口头承诺。
- **储存**：硅橡胶的耐老化性在所有弹性体里数一数二，避光、25℃ 以下、远离臭氧源和含硫材料存放，**保质期可超过 10 年**——比 NBR、EPDM 都好，适合备件库存。
- **安装**：硅橡胶撕裂强度低，装配时务必倒角、用安装套筒，并涂抹硅脂（如 Molykote 111）。**绝不能用凡士林或矿物油做装配润滑**，那等于让它从安装那一刻就开始溶胀。

---

**一句话总结**：硅橡胶是"极端温度 + 食品医疗 + 电气绝缘"三个场景的正确答案，但它在油、蒸汽、动态摩擦面前基本没有战斗力。选之前先确认介质——介质里有油，直接跳到 FKM 或 HNBR 那一页。

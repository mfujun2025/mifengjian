拿到一张图纸写着 `O 型圈 20×2.65`，或者拿到一个实物不知道型号——这两种情况都指向同一套规则。搞清这套规则，比背一张规格表更有用。

## 一、规格代号读法

国标体系的写法是：

```
O 形圈  d1 × d2  材料代号  GB/T 3452.1-2005
例：O 形圈 20 × 2.65  NBR  GB/T 3452.1-2005
```

- **d1 = 内径**（第一个数字）
- **d2 = 截面直径**，也叫线径（第二个数字）
- 单位默认毫米

所以 `20×2.65` 的意思是：内径 20 mm、截面直径 2.65 mm。

**最常见的读错方式**是把第一个数字当成外径。记住顺序是"先内后截"，行业里没有"外径×截面"的主流写法。

## 二、外径是算出来的，不是标出来的

这是最关键的一点：

> **外径 d3 = 内径 d1 + 2 × 截面 d2**

`20 × 2.65` 对应外径 = 20 + 2×2.65 = **25.3 mm**。

为什么外径不单独规定？因为 O 型圈是弹性体，外径由内径和截面推导，标准只需要管住这两个基本尺寸及其公差就够。所以你查不到一张"国标外径表"——外径是计算值。

**实用推论**：
- 现场测量时量**内径**最可靠，外径会因为拉伸/挤压状态不同而漂移；
- 内径量不准时，可以量外径反推：`d1 = d3 − 2×d2`，前提是截面要先量准。

## 三、公差怎么查

GB/T 3452.1-2005 分别规定了内径公差与截面公差。

**截面公差**（固定值，按截面尺寸分档）：

| 截面 d2 (mm) | 公差 (±mm) |
|---|---|
| 1.80 | 0.08 |
| 2.65 | 0.09 |
| 3.55 | 0.10 |
| 5.30 | 0.13 |
| 7.00 | 0.15 |

**内径公差**（按内径大小分档，内径越大公差越宽）：

| 内径 d1 (mm) | 公差 (±mm) |
|---|---|
| ≤ 6.3 | 0.13 |
| 6.7 ~ 10 | 0.14 |
| 10.6 ~ 18 | 0.17 |
| 19 ~ 30 | 0.22 |
| 31.5 ~ 50 | 0.30 |
| 51.5 ~ 80 | 0.45 |
| 82.5 ~ 118 | 0.65 |
| 122 ~ 180 | 0.90 |
| 185 ~ 280 | 1.20 |
| 290 ~ 400 | 1.60 |

用[规格查询工具](/tool/)输入尺寸会直接带出对应公差，不用翻表。

## 四、内径系列为什么是这些"怪数字"

`1.8、2.24、2.65、3.15、3.55、4.87、5.3、6.3、8.75、22.4、23.6、38.7、41.2……`——这些数字看起来不规则，其实来自**优先数系（R10 / R20）**。

优先数系是按等比数列划分的尺寸梯度，好处是：任何一段尺寸区间内的规格数量大致均衡，既不会出现"1mm 一个规格太密"，也不会出现"20mm 一个跳档太疏"。ISO 体系里的标准件尺寸（轴承内径、螺纹、O 型圈内径）大量采用这套数系。

这也解释了一个现象：**你为什么在市场上找不到内径 21.5 的国标 O 型圈**——它不在优先数系里。要么改设计用 21 或 22.4，要么按非标定制。

## 五、截面系列只有五档（G 系列）

GB/T 3452.1-2005 的 G 系列（一般应用）规定 5 个截面：

**1.8 / 2.65 / 3.55 / 5.3 / 7.0 mm**

它们的适用范围大致是：

| 截面 | 典型应用 |
|---|---|
| 1.8 | 小直径、仪表、精密小件、低压 |
| 2.65 | 最通用，中小型液压/气动 |
| 3.55 | 中型液压缸、法兰面静密封 |
| 5.3 | 大直径、较高压力 |
| 7.0 | 超大直径、重载、大压缩量 |

**选截面比选内径更容易出错**。同一个内径可能对应 2~4 种截面（例如内径 20 就有 1.8、2.65、3.55 三种），截面选错会直接破坏压缩率——截面偏小则压缩量不足、易泄漏；截面偏大则装不进沟槽、剪切破坏。

## 六、四个常见标注/测量错误

**错误 1：把外径写在第一位。**
`25.3×2.65` 会被供应商理解成内径 25.3 的规格，而国标里内径 25.3 并不存在，于是被当成非标件报价，价格翻倍。正确写法是 `20×2.65`。

**错误 2：用卡尺量外径就下单。**
旧圈拆下来往往是椭圆、被压扁的，外径测量值包含变形量。应测量**截面直径**并用内径定位，或把圈套在标准芯棒上测量。

**错误 3：把英制尺寸当国标尺寸。**
AS568 的 `-210` 之类编码对应的是英制尺寸（如内径 0.734"），它和国标内径 18.64 mm 接近但**不相等**，且公差体系不同，不能直接替换。

**错误 4：忽略公差就做沟槽。**
沟槽设计要按"内径公差下限 + 截面公差上限"这类极限组合校核，只按公称尺寸算会导致部分批次的圈压不进或过松。

## 七、内径量不准时怎么办

现场最实用的一条经验：**旧件长期受压后，实测内径通常略小于原始尺寸**。如果测量结果正好卡在两个标准规格中间，优先选内径略大的一侧——因为 O 型圈安装时会被拉伸约 1%~5%，靠压缩量补偿比靠拉伸补偿可靠得多。

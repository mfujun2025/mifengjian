一台化工装置的不锈钢法兰，用 FKM 圈封了不到两个月就漏。拆开一看，圈已经泡胀到原来的 1.3 倍——介质里有甲乙酮，正是氟橡胶的禁区。换成聚四氟乙烯（PTFE）圈，介质问题立刻消失，可一打压又开始渗。

原因不在材质，在结构：**PTFE 不是橡胶，它不会回弹。**

这个差别决定了 PTFE 的真实身份：它很少作为"一种橡胶"的形式被使用，而是以**四种完全不同的结构**出现。搞不清这一点，比选错材质更容易出事。

## 一、"几乎耐所有化学品"这句话是怎么来的

PTFE 的分子是一条碳链，每个碳原子两侧挂满氟原子，形成一层致密的"氟鞘"。碳氟键能约 485 kJ/mol，是已知最强的单键之一，绝大多数化学试剂根本接触不到碳链本体。结果是：

| 项目 | 数值 | 说明 |
|---|---|---|
| 长期使用温度 | -200 ~ 260 ℃ | 短时可到 300 ℃，熔点 327 ℃ |
| 本站工具口径 | -60 ~ 260 ℃ | 按"包覆圈"这一常见形态记录，低温下限受内芯牵制 |
| 摩擦系数 | 0.05 ~ 0.10 | 固体材料中最低的一档，自润滑，几乎不爬行 |
| 线膨胀系数 | 112 ~ 125 ×10⁻⁶ /K | 约为钢的 10 倍，Φ100 的圈升温 100℃ 直径约涨 1.2 mm |
| 吸水率 | < 0.01 % | 不溶胀、不水解，尺寸最稳定的一类密封材料 |
| 拉伸强度 | 20 ~ 35 MPa | 绝对值不低，但断裂伸长率只有 200~400% |
| 硬度 | 邵氏 D 55 ~ 65 | 塑料量级，与橡胶的 70~90 Shore A 不是同一把尺子 |
| 表面能 | < 19 mN/m | 极低，不粘料、不易挂料，也意味着"贴不住" |

前两行最值钱：能把**强酸、强碱（含氢氟酸、王水）、强氧化剂、芳香烃、酮酯溶剂**一网打尽的材料，工业上只有它和 FFKM 两种选择，而 PTFE 便宜得多。

后三行是它的代价：**没有弹性、膨胀大、不粘。**

## 二、禁区清单：有几类介质它真的碰不得

"几乎"不等于"全部"。下面几条一旦踩中就是直接失效：

**1. 熔融碱金属（钠、钾）。** 高温下的碱金属会直接夺取氟原子、打穿分子链。钠冷快堆、钠回路里不能用 PTFE 密封。

**2. 元素氟与强氟化剂。** 常温低压的氟气勉强可用，高温加压的氟气、以及三氟化氯（ClF₃）这类氟化剂会腐蚀它。

**3. 高能辐射。** PTFE 是高分子材料里最不耐辐照的一类，射线会直接切断主链。有辐照灭菌的医疗器械，PTFE 密封件必须单独评估剂量。

**4. 高温下的活泼金属。** 铝、镁等在高温下会与 PTFE 反应（含镁烟火剂的原理就来自这里）。铝制腔体在高温工况要留个心眼。

**5. 等离子体。** 这一条最容易被忽略：工业上用氧等离子体给 PTFE 表面"活化改性"，用的正是它会被等离子体刻蚀的性质。所以**半导体湿法药液槽可以用 PTFE/PFA，等离子体腔体不能用**——腔体密封要选专用 FFKM。

## 三、四种形态：先问"靠什么提供压紧力"

PTFE 没有回弹，所以真正决定密封成败的不是材质，而是**用什么力量把它压在密封面上**。按这个标准，市面上的 PTFE 密封件分成四类：

| 形态 | 结构 | 该用在哪 | 不该用在哪 |
|---|---|---|---|
| 纯 PTFE 圈 | PTFE 整体车削的矩形圈或 O 形圈 | 端面静密封、低压、要求全介质兼容 | 需要靠自身回弹复位的场合 |
| PTFE / FEP / PFA 包覆 O 型圈 | 氟聚合物薄套 + 橡胶内芯（FKM 或硅橡胶） | 常说的"PTFE O 型圈"多数就是它；静态或极慢速动密封 | 液压缸往复、旋转动密封 |
| 弹簧蓄能密封（泛塞封） | PTFE U 形唇 + 金属弹簧（V 形 / 螺旋 / 线簧） | 真空、深冷、压差极低也要密封的场合 | 高线速度旋转、粗糙密封面 |
| PTFE 挡圈（支承环） | 斜切口 / 螺旋多圈 / 整体环 | 高压下防止 O 型圈被挤进间隙 | 不能当主密封单独使用 |

一句话选择法：**靠螺栓压紧 → 纯 PTFE 圈；靠橡胶回弹 → 包覆圈；靠金属弹簧 → 蓄能圈；只为挡挤出不承担密封 → 挡圈。**

## 四、包覆圈：芯材与包覆层的温度要取交集

包覆圈是把弹性短板"外包"出去的解法：外层耐介质，内芯管回弹。但两层的极限不同，实际温域取**两者中先到极限的那一个**。

| 包覆层 | 最高连续温度 | 特点 |
|---|---|---|
| FEP | 约 205 ℃ | 供货面最广、相对便宜，化学兼容性够用 |
| PFA | 约 260 ℃ | 机械强度、抗蠕变与耐应力开裂更好，用于高温与长寿命场合 |

| 内芯 | 低温下限 | 说明 |
|---|---|---|
| 实心硅橡胶 | 约 -60 ℃ | 回弹好、所需压紧力小，最常用 |
| 实心 FKM | 约 -26 ℃ | 抗压缩永久变形更好，低温吃亏 |
| 空心硅橡胶 | 约 -60 ℃ | 更易压缩，适合低压差、真空与陶瓷/玻璃等脆性密封面 |
| 不锈钢弹簧 | 约 -250 ℃ | 液氧、液氢、LNG 等深冷工况 |

两条硬规则：

- **不能只看包覆层**。PFA 套能到 260 ℃，可硅胶芯长期只有 200 ℃ 上下、FKM 芯还更低。选了 PFA 配硅胶芯，实际温域被芯材卡住——询价时必须写清芯材，只说"要耐 260℃"供应商会按最便宜的配。
- **低温同样由芯决定**。本站工具给 PTFE 记的 -60 ℃ 就是硅胶芯的下限；换成 FKM 芯，低温只能到 -26 ℃ 上下。

## 五、沟槽与安装：包覆圈不能按橡胶圈的规矩来

包覆圈比同尺寸橡胶圈"硬"，压缩它需要更大的压紧力；外层套壁又薄又脆，一道划痕就是一条泄漏路径。沟槽和手法都要改：

| 项目 | 包覆圈 | 普通橡胶 O 型圈 |
|---|---|---|
| 静密封压缩率 | 15% ~ 20%（典型）；大压紧力结构可取 20%~25% | 20% ~ 30% |
| 沟槽深度 | 约取截面的 75% ~ 80% | 由压缩率反算 |
| 安装拉伸率 | ≤ 2% ~ 3% | 0 ~ 5% |
| 空腔率 | ≤ 85% | ≤ 85% |
| 倒角 | 15° ~ 20°，长度不小于 1 个截面 | 同样要求 |
| 越过螺纹 / 键槽 | 必须有退刀槽，深度 ≥ 截面 + 0.5 mm | 建议做 |
| 装前处理 | 100 ℃ 热水泡 ≥3 分钟，或烘箱 ≥15 分钟，趁热装 | 视情况 |

三条红线：

- **不许用螺丝刀、钩子撬**。只能用钝头塑料套筒或戴手套推送，螺纹口必须先做退刀槽或套塑料导套。
- **不许拉伸安装**。拉伸超过 3% 就应报废换新——套壁拉薄发白不是外观问题，是结构损伤。
- **不做往复动密封**。液压缸活塞杆那种往复摩擦会在几小时到几天内把套壁搓裂，接着介质直接攻击内芯。动密封用 PU、NBR、FKM，或者改用弹簧蓄能 PTFE 密封。

## 六、高压工况：PTFE 更常见的身份其实是挡圈

O 型圈被挤出的门槛大约在 **10 MPa（约 1500 psi）**。压力再高，橡胶会被压进配合间隙，边缘一层层被剪掉，现场叫"啃边"。挡圈就是挡这件事的。

| 工况 | 挡圈选择 |
|---|---|
| 常温、≤ 20 MPa | 纯 PTFE 挡圈（斜切口或螺旋多圈便于装配） |
| 20 ~ 35 MPa 或高温工况 | 碳 / 石墨填充 PTFE（抗蠕变、导热好） |
| 更高压力、极端温度 | PEEK 挡圈 |

- 单向受压装 1 个，装在**低压侧**；双向受压则 O 型圈两侧各装 1 个。
- **挡圈材质必须比 O 型圈硬**——这是基本原理，也是它敢挡挤出的原因。
- 挡圈的径向宽度要同时覆盖沟槽深度和挤出间隙（挡圈宽度 = 沟槽深度 + 间隙），所以它是按沟槽配的非标件，不是通用件。
- 加挡圈意味着**沟槽宽度要加宽一个挡圈厚度**；沟槽太窄放不下时，只能改用 90 Shore A 的 O 型圈硬扛，或者缩间隙。

## 七、场景对照与采购验收

| 工况 | 建议方案 |
|---|---|
| 磷酸酯液压油（如航空 Skydrol） | PTFE 包覆圈，或 EPDM（EPDM 更便宜但只到 150℃） |
| 200 ℃ 以上蒸汽、热油 | PFA 包覆 + 弹簧芯；EPDM 已到极限 |
| 浓酸浓碱泵阀、法兰 | PTFE 包覆圈 / PTFE 包覆垫片 |
| 食品、制药 CIP / SIP | PFA / FEP 包覆，索取 FDA 21 CFR 177.1550、USP Class VI、3-A 文件 |
| 液氮、液氧、LNG | 弹簧蓄能 PTFE 密封 |
| 半导体湿法槽、超纯水 | PFA / PTFE 包覆圈 |
| 等离子体腔体 | 不用 PTFE，选专用 FFKM |
| 高压液压缸（>16 MPa） | PTFE 挡圈 + 90 Shore A O 型圈，而不是包覆圈 |
| 旋转轴、往复杆 | 不用包覆圈，改用油封或 PU |

采购与验收的实操要点：

- **规格写三层**：包覆层（FEP 还是 PFA，不要只写"PTFE"）、内芯（硅胶 / FKM / 空心 / 弹簧）、成品实测内径 × 截面。包覆后截面比标称橡胶圈略大，**不要只报一个 AS568 编号了事**，以供应商提供的成品尺寸为准。
- **高压气体工况要问通气孔**。快速泄压时套壁内的气体会膨胀，没有泄压设计可能鼓泡甚至破裂，属于结构选型问题而非质量缺陷。
- **填充料的取舍**：玻璃纤维填充提高抗压与抗蠕变，但**不耐氢氟酸与热碱**；碳 / 石墨填充耐磨导热，但会导电；青铜填充抗压与导热最好，却不耐化学；MoS₂ 主要降摩擦。要极致化学兼容就用纯料，要抗蠕变就得上填充，两者不能同时拿满。
- **来料检查**：划伤、针孔、气泡、接缝分层、永久压扁，任何一项都应拒收；内径与截面用卡尺实测，别靠手感。
- **储存**：PTFE 本体几乎不老化，但内芯是橡胶。按橡胶件规则管理：避光、远离臭氧源、25 ℃ 以下存放，超过 5 年建议抽检后再用。

---

**一句话总结**：PTFE 解决的是"介质兼容"和"高温"，它从不解决"回弹"。拿到工况先问两个问题——**靠什么提供压紧力？有没有相对运动？** 这两问答完，形态（纯圈 / 包覆圈 / 蓄能圈 / 挡圈）就定了，材质只是收尾。

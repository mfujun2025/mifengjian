同一个液压站，同样的 110℃ 油温：装 NBR 圈的工位三个月后硬化、压扁、开始渗油，换 HNBR 之后能撑两年。很多人以为这是"配方更好"或者"添加剂更高级"，其实不是——**HNBR 变强的唯一原因，是它的分子链上被拿掉了一样东西。**

## 一、加氢：把分子链上的薄弱环节拆掉

丁腈橡胶 NBR 是丁二烯与丙烯腈的共聚物。丙烯腈带来极性，让它耐油；而丁二烯那一段留下了大量 **C=C 双键**。麻烦就出在这里：

- 双键旁边的**烯丙基氢**很容易被夺走，一旦被夺走就启动自由基链式反应，橡胶交联、变硬、失去回弹——这就是热氧老化；
- 双键本身是臭氧和紫外线的进攻点，臭氧会顺着它把分子链切断，表面出现细密裂纹——这就是臭氧开裂。

HNBR 的做法很直接：**用催化加氢把丁二烯段的双键选择性饱和掉。** 氢化程度高的牌号饱和度可达 95%~99%（碘值降到个位数，普通 NBR 的碘值在数十的量级）。双键没了，上面两条老化通路就同时被掐断。

所以 HNBR 的耐热上限比 NBR 高约 50℃、耐臭氧耐候接近 EPDM，**不是靠添加剂堆出来的，是结构本身给的。**这一点很重要——它意味着这些性能不会随时间的助剂消耗而衰减。

同时，丙烯腈这一头的极性基团被完整保留，**耐矿物油、耐燃油的能力一点没丢**。用一句话概括 HNBR 的定位：

> NBR 的极性骨架 + EPDM 的饱和主链。

这句话也解释了它和两者的区别：EPDM 主链同样饱和、同样耐臭氧，但它是非极性橡胶，遇矿物油必溶胀；NBR 极性够、耐油好，主链却满是不饱和双键。HNBR 把这两种材料各自的长处拼在了一起，代价是价格。

## 二、温度：150℃ 长期，165℃ 峰值

| 项目 | 数值 | 说明 |
|---|---|---|
| 长期工作温度 | -40 ~ 150 ℃ | 标准牌号 |
| 短时峰值 | 约 165 ℃ | 部分资料给到 170~180℃，但不应按峰值规划寿命 |
| 低温下限 | -40 ℃ | 低丙烯腈特殊牌号可更低，以供应商牌号数据为准 |
| 常用硬度 | 70 / 80 / 90 Shore A | 供货范围 60~90 |
| 常规丙烯腈含量 | 34%~36% | 全系列范围 17%~50% |
| 拉伸强度 | 15~35 MPa | 高于普通 NBR |
| 压缩永久变形 | 15%~25%（150℃ × 70h） | 过氧化物硫化牌号表现最好 |

两个必须说清的细节。

**第一，150℃ 是长期上限，不是峰值。**和所有橡胶一样，贴着上限长期跑要付寿命账。如果实际工况长期在 145~150℃，建议在结构上留出散热或加大截面余量，别把余量全部吃掉。

**第二，加氢是有代价的：低温性能会略逊于同档次 NBR。**饱和之后分子链活动性下降，玻璃化转变温度有所上升，同样的丙烯腈含量下，HNBR 的低温表现会比 NBR 差一点——它换来的是 50℃ 的高温收益。所以"既要 -50℃ 又要 150℃"的工况，HNBR 也做不到，那属于氟硅橡胶 FVMQ 或硅橡胶的领域。

## 三、它真正耐受的介质

加氢没有改变丙烯腈基团，所以 **HNBR 的耐油表现基本等于 NBR**，只是边界更宽了一点：

| 介质 | 评价 | 说明 |
|---|---|---|
| 矿物液压油、机油、齿轮油 | 推荐 | NBR 的主力场景，HNBR 同样胜任 |
| 汽油、柴油、燃油 | 推荐 | 燃油系统密封、喷油嘴周边常用 |
| 乙二醇型防冻液、长效冷却液 | 推荐 | 对冷却液中的添加剂耐受性优于 NBR |
| HFC 制冷剂（R134a 等） | 推荐 | 空调压缩机轴封的常见选择 |
| 常温清水 | 推荐 | 冷水工况可用 |
| 稀酸、稀盐溶液（常温） | 推荐 | 优于 NBR |
| 芳香烃（苯、甲苯） | 有限 | 高丙烯腈牌号更好，浓度高时务必做浸泡实测 |
| 硫化氢酸性气、原油介质 | 需选专用牌号 | 油田井下工况普遍采用 HNBR，但必须拿到供应商在对应介质下的实测报告 |

## 四、仍然碰不得的介质（三条必记）

HNBR 常被误当成"NBR 的全面升级版"，事实是：**它的耐热和耐臭氧升级了，耐化学品的覆盖面几乎没有扩大。**下面几条和 NBR 一样是禁区。

**1. 酮类与酯类溶剂**

丙酮、丁酮（MEK）、乙酸乙酯，以及合成酯型液压油、部分环保压缩机油。加氢只解决了双键问题，丙烯腈基团的极性决定了它对强极性溶剂依然敏感，会出现明显溶胀与强度下降。

**2. 醇醚型刹车油（DOT3 / DOT4）与磷酸酯抗燃液压油**

这两类介质必须用 **EPDM**，HNBR 和 NBR 一样会被溶胀。制动系统里看到 HNBR 圈，基本可以判定为误用。

**3. 高温蒸汽与热水（长期）**

HNBR 短期接触热水尚可，但长期高温水蒸汽会导致水解老化。长期蒸汽工况的标准答案依然是 **EPDM**——耐温上限与 HNBR 相当（同为 150℃），耐蒸汽能力却是另一个量级，而且更便宜。

此外，**强酸、强氧化剂、氯代烃**同样不适用。

## 五、过氧化物硫化还是硫黄硫化，采购必须分清

这是 HNBR 采购里最容易被含糊过去的一环。同样叫 HNBR，硫化体系不同，性能和用途差得明显：

| 项目 | 过氧化物硫化 | 硫黄硫化 |
|---|---|---|
| 长期耐热上限 | 高，可稳定到 150℃ | 相对较低 |
| 压缩永久变形（150℃ × 70h） | 优，约 15% | 偏差 |
| 动态性能与回弹性 | 一般 | 好，适合反复动作 |
| 撕裂与低温柔顺性 | 一般 | 较好 |
| 典型用途 | 高温静密封、O 型圈、油封 | 正时皮带、动态密封件 |
| 成本 | 略高 | 略低 |

判断规则很简单：**工位是高温静密封，就指定过氧化物硫化**——它的价值恰恰体现在压缩永久变形上，也就是"用了两年还能弹回来"。反过来，需要反复屈挠、要求回弹和抗疲劳的场合（比如同步带），硫黄硫化反而更合适。

食品接触场合还要额外确认：必须选过氧化物硫化，且配方按 **FDA 21 CFR 177.2600** 白名单原料设计。

## 六、HNBR、NBR、FKM 到底怎么选

| 你的工况 | 建议 | 理由 |
|---|---|---|
| 长期 ≤100℃、矿物油、普通静密封 | **NBR** | 够用，价格最低，不需要升级 |
| 长期 100~150℃、接触矿物油或燃油 | **HNBR** | 保留耐油性，耐温多 50℃ |
| 长期 150~200℃、接触油或燃油 | **FKM** | 高温耐油的标准答案 |
| 户外暴露、电机附近、有臭氧 | **HNBR** 或 EPDM | 按是否接触油品来定 |
| 耐 H2S、油田井下高压 | HNBR 专用牌号 / FFKM | 需对应介质实测报告 |
| 刹车油、磷酸酯抗燃液压油 | **EPDM** | HNBR、FKM 都会溶胀 |
| 长期蒸汽、高温热水 | **EPDM** | 耐蒸汽能力不在一个量级 |
| 酮类、酯类溶剂 | FFKM / PTFE 包覆 | 见[材质百科](/materials/)极端工况方案 |

成本梯度大致是：**NBR < HNBR（约 NBR 的 2~3 倍）< FKM < FFKM**。

这里有一个很实用的判断逻辑：**先看失效是什么原因造成的。**

- 如果是**热老化、硬化、压缩永久变形、臭氧开裂**——说明材质选低了，从 NBR 换 HNBR 是对的，而且性价比很高，比直接跳到 FKM 省一大截。
- 如果是**溶胀、发胖、变软、被溶解**——问题出在介质不兼容，换 HNBR 完全没用，必须换到另一个材质族（EPDM、FKM 或 FFKM）。

把这两类失效分开，八成的选型纠结就自动消失了。

## 七、采购与验收要点

- **问丙烯腈含量**，不要只写"HNBR"。34% 与 19% 的牌号在耐油和低温上完全不是一个产品。
- **问氢化度**。高饱和度牌号（95% 以上）才有对应的耐热耐臭氧表现，低饱和度 HNBR 的性能介于 NBR 与 HNBR 之间。
- **问硫化体系**。高温静密封要过氧化物硫化，并写进规格书。
- **硬度**按工况定：70 Shore A 通用，80~90 Shore A 用于高压抗挤出场合。
- **颜色**可作辅助辨识：HNBR 常见黑色与绿色，绿色是不少厂家用于区分 HNBR 的标识色。但颜色不是判据，最终仍要凭材质报告。
- **要三类报告**：对应介质的浸泡试验（介质、温度、时长、体积变化率、硬度变化）、热空气老化试验（150℃ × 70h 的硬度与拉伸强度变化率）、压缩永久变形数据。**150℃ 老化后硬度上升超过 15 Shore A，就要警惕配方水平。**
- **储存**：HNBR 避光、避臭氧源，与含硫材料分开存放，室温下保质期通常优于 NBR。

---

**一句话总结**：HNBR 是把 NBR 的双键加氢饱和的产物，用 2~3 倍的价格买到 +50℃ 耐温、耐臭氧耐候和更好的压缩永久变形，但耐化学品范围基本没变。**失效原因是热和臭氧，换 HNBR 值得；失效原因是溶胀，换 HNBR 没用。**

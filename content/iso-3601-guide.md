一份国产化技术协议里，工程师写了两条：尺寸按 GB/T 3452.1，外观按 GB/T 3452.2。对外询价时，同事按「国标第几部分＝国际标准第几部分」的习惯翻译成英文，写成 `visual per ISO 3601-2`。

问题来了：ISO 3601-2 讲的是**沟槽尺寸**，一个字都没提外观，外观在 ISO 3601-3。这份询价单发出去，供方要么来问，要么按自己的理解报——两种都很麻烦。

错不在英文，在于**这套标准家族里，国标的第 2 部分和国际标准的第 2 部分，管的不是同一件事。**

## 一、ISO 3601 是五个部分，不是一个标准

「按 ISO 3601 供货」这句话的信息量，约等于「按国家标准供货」。它是一族标准，五个部分各管一段：

| 部分 | 管什么 | 现行版本 | 对应的国标 |
|---|---|---|---|
| ISO 3601-1 | 内径、截面、公差与尺寸识别代码 | 2012 年版 | GB/T 3452.1-2005 |
| ISO 3601-2 | 沟槽（安装腔）尺寸 | 2025 年第三版 | GB/T 3452.3-2005 |
| ISO 3601-3 | 外观质量验收准则与缺陷分级 | 2005 年版 | GB/T 3452.2-2007 |
| ISO 3601-4 | 抗挤出挡圈（支承环） | 2008 年版 | GB/T 3452.4-2020 |
| ISO 3601-5 | 工业用 O 型圈弹性体材料规范 | 2015 年版 | GB/T 3452.5-2022 |

五个部分的分工是硬边界：**第 1 部分管圈本体，第 2 部分管装它的槽，第 3 部分管它长什么样算合格，第 4 部分管高压下的挡圈，第 5 部分管它用什么胶。任何一部分都不能代替另一部分。**

一句话写「符合 ISO 3601」，五个部分里只要有一个对不上，整条密封链就是断的——而且断裂点往往不在圈上。

## 二、编号错位：ISO 3601-2 对的是 GB/T 3452.3

把上表最后两列并排看，错位就出来了：

| ISO 部分 | 内容 | 对应的 GB/T 部分 |
|---|---|---|
| ISO 3601-1 | 尺寸与公差 | GB/T 3452.1 |
| **ISO 3601-2** | **沟槽尺寸** | **GB/T 3452.3** |
| **ISO 3601-3** | **外观质量** | **GB/T 3452.2** |
| ISO 3601-4 | 挡圈 | GB/T 3452.4 |
| ISO 3601-5 | 材料规范 | GB/T 3452.5 |

第 2 位和第 3 位是对调的。国标的排列顺序是「尺寸 → 外观 → 沟槽 → 挡圈 → 材料」，ISO 的排列顺序是「尺寸 → 沟槽 → 外观 → 挡圈 → 材料」。**按序号类推，就会把沟槽标准当成验收标准用。**

后果很具体：协议写「沟槽按 GB/T 3452.2」，你拿到的是一份缺陷分级规范，里面没有一行槽深数据；协议写「外观按 ISO 3601-2」，供方按尺寸类标准交货，没人对外观负责。这两句话都不是笔误能解释的——它们看起来太顺了。

**判断口诀：只有 1、4、5 三个部分的序号是对齐的，2 和 3 必须单独记。**

## 三、ISO 3601-1 内部还分 G 系列和 A 系列

就算把部分号写对了，第 1 部分里面还有一层分支：

| 系列 | 用途 | 规格数 | 公差取向 |
|---|---|---|---|
| G 系列 | 一般用途：液压、气动、泵阀、一般工业 | 445 个 | 基准 |
| A 系列 | 航空及类似应用 | 383 个 | 明显收紧，约为 G 系列的一半 |

内径 d1 取自优先数系，所以你会看到 9.75、11.2、12.1、25.8 这类不像整数的规格——它们是算出来的，不是凑的。

这一层与站内另一篇直接接得上：**日标 JIS B 2401 里那套「ISO 一般工业用、后缀 G」的 445 个规格，就是这里说的 ISO 3601-1 G 系列。** 同一个尺寸库，换了一本册子在讲。

第 1 部分还规定了一套**尺寸识别代码（size code）**，六位字母数字，结构是「截面字母 ＋ 四位内径数字 ＋ 应用字母」：

| 第 1 位（截面） | 1.8 | 2.65 | 3.55 | 5.3 | 7.0 |
|---|---|---|---|---|---|
| 字母 | A | B | C | D | E |

四位内径数字的单位是 0.1 mm，小数点默认点在第三位数字之后。所以 `C0500A` 是截面 3.55、内径 50.0 的航空用圈；`D2300G` 是截面 5.3、内径 230 的一般用途圈。

注意两件事：一是这套代码**不是** AS568 的 dash 号，`-214` 换算不出 ISO 代码，`C0500A` 也换算不出 dash 号；二是 ISO 与 AS568 的**截面档位其实非常接近**（差在 0.03 mm 以内），真正对不上的是**内径数列与编号体系**。换件时把力气花错地方，是最常见的浪费。

## 四、G/A、class A/B、N/S/CS：同一个家族里三套字母

这个家族里出现三组字母，含义完全不同：

**第 1 部分的 G / A**，分的是用途（一般工业还是航空）。

**第 2 部分的 class A / class B**，分的是沟槽给谁用。ISO 3601-2:2025 规定了两类圈的安装腔尺寸：class A 圈（符合 ISO 3601-1、用于一般工业）的沟槽，以及用在选定公制硬件上的 class B 圈的沟槽——液压缸孔、活塞杆都在里面。它同时把工业界的两种设计路径都收进来了：**以圈定槽**（先选圈，再算最优硬件尺寸）和**以槽选圈**（孔和杆已经定了，反过来挑圈）。维修现场属于后者，不用自己推公式；航空用圈的安装腔尺寸单独放在附录 A。

**第 3 部分的 N / S / CS**，分的是外观验收等级：N 一般工业、S 汽车与精密装配、CS 关键服役。这是缺陷限值，跟尺寸公差没有关系。

**所以文件上只写字母不写部分号，对方没有依据判断你说的是哪一套。** 采购单上那句「按 A 级供货」，三种解释都成立。

## 五、等同采用和修改采用，差在哪

国标与 ISO 的关系不是统一的，逐条看：

| 国标 | 对应的 ISO 版本 | 采用方式 |
|---|---|---|
| GB/T 3452.1-2005 | ISO 3601-1:2002 | 修改采用（MOD） |
| GB/T 3452.3-2005 | ISO 3601-2:1999 | 修改采用（MOD） |
| GB/T 3452.2-2007 | ISO 3601-3:2005 | 等同采用（IDT） |
| GB/T 3452.4-2020 | ISO 3601-4:2008 | 修改采用（MOD） |
| GB/T 3452.5-2022 | ISO 3601-5:2015 | 修改采用（MOD） |

采标方式可以直接看标准文本首页的「采标情况」栏核对。为什么值得核：**等同采用意味着技术内容一致，两边可以互相引用；修改采用允许存在差异，不能默认「按国标做的」就等于「按 ISO 做的」。** 出纠纷时，这一栏决定按哪份文本判。

更要紧的是第二列——版本滞后：

- **GB/T 3452.1-2005 锁的是 ISO 3601-1:2002**，而 ISO 现行版是 2012 年版（另有 2019 年修正案）；
- **GB/T 3452.3-2005 锁的是 ISO 3601-2:1999**，而 ISO 现行版已经出到 2025 年第三版，替代了 2016 版，正文 55 页。

也就是说，同一句「符合 ISO 3601-1」，如果对方手里是 2012 版、你手里是 2002 版，你们看的不是同一份文本。出口订单尤其要注意：**客户写 ISO，就按 ISO 的版本号写，不要自动翻译成国标号**；反过来也一样。

## 六、ISO 3601-5 只给基线材料，不等于材料合格

第 5 部分最容易被人过度使用。它的实际口径是：只把**普遍使用**的弹性体材料纳进来，其他配方胶料同样可以用，而**具体物理性能与试验方法，由用户与供方约定**。

所以「材料按 ISO 3601-5」落到实处，只是「材料是工业 O 型圈常用弹性体之一」，离「材料合格」还很远。材料条款至少要写四样：**胶种 ＋ 硬度 ＋ 压缩永久变形条件 ＋ 试验方法**。例如：

> NBR，70 Shore A；压缩永久变形按 GB/T 7759.1-2015（等同 ISO 815-1）25% 压缩率、100℃×70h 不大于 35%；耐介质按 GB/T 1690（等同 ISO 1817）。

三条材质红线顺便再钉一遍，与站内工具页是同一口径：**硅橡胶 VMQ 与 EPDM 都不耐矿物油**；**FKM 不耐酮类、酯类与热水蒸汽**；**NBR 不耐臭氧与醇醚型刹车油**。材质选完之后，再回来核对沟槽与压缩率——顺序反了，返工的是硬件。

## 七、对外文件的三条写法

**第一，标准号写全：部分号 ＋ 年号。** 写 `ISO 3601-1:2012`，不写 `ISO 3601`；写 `GB/T 3452.1-2005`，不写「按 3452」。少写一个部分号，可能差一整本册子。

**第二，五个部分逐条落位。** 尺寸、沟槽、外观、挡圈、材料各写一句依据，缺哪项就写「由双方约定」，不要留空。留空的条款在验收时会被两边各自解释。

**第三，不做跨标准自动翻译。** 客户给 ISO 就写 ISO，给 AS568 的 dash 号就保留 dash 号——`-214` 折算成公制再报价，争议只会更多。
